# S12 — Оболочка TV-интерфейса: концепция

Этап проекта `docs/projects/plezy-tv/project.md`, S12. Предпосылки проекта не проверены заранее;
факты об апстриме ниже — из чтения кода Plezy в этом репозитории (2026-10-23), сборкой не проверены.

## 1. Проблема, пользователи, результат

На TV профиль сейчас открывает апстримный `MainScreen` внутри `TvShell` (итог S3). Свои экраны главной (S15),
библиотеки (S16) и остальные подключить некуда: экраны и меню живут внутри файла на 2,3 тыс. строк, который
мы не правим. Пользователь — владелец и его семья на трёх Android TV (Xiaomi, Mi Box 4, TCL), с пультом.

Результат: на TV вместо `MainScreen` работает своя оболочка — боковое меню по дизайну и область раздела.
Внутри разделов пока апстримные экраны. Всё, что Plezy делает при запуске и в фоне, продолжает работать.
Телефон и планшет не меняются.

## 2. Объём и решения

Решения пользователя (2026-10-23):

- S12 — только оболочка; главная — S15, сетка библиотеки — S16. Общие контролы уже есть в S6, детали экранов
  делают их этапы.
- Меню — реальные пункты Plezy, не пункты макета: Поиск, Главная, по пункту на каждую видимую библиотеку
  (одинаковые названия — с именем сервера), Live TV и Explore при наличии, «Сейчас играет» только пока играет
  музыка, Загрузки (если включены), Настройки. «Список» добавит S10. Профиля в меню нет — смена профиля в
  настройках, как в Plezy.
- Внешний вид меню — `docs/design/screens/01-home-sidebar-expanded.png` и компонент `TvSideMenu` из S6:
  колонка иконок, при фокусе раскрывается с подписями и затемняет контент. Много библиотек — меню прокручивается.
- «Ещё» внизу библиотек, как в Plex: экран всех библиотек по серверам, включая скрытые; выбор открывает
  библиотеку. Пункт показывается, только если добавляет что-то к меню (есть скрытые библиотеки или серверов
  больше одного).
- Загрузки на TV по умолчанию скрыты, включаются настройкой.
- Офлайн (нет связи ни с одним сервером): в области раздела — экран ошибки по `09-state-error-server.png`:
  «Повторить» (переподключение) и «Выбрать другой сервер», если в Plezy есть такой выбор (проверить в
  требованиях). Меню остаётся: Настройки, Загрузки — если включены. Отдельного пункта «Переподключиться» нет.
- Пункт библиотеки открывает апстримный экран библиотеки сразу на ней.
- Стартовый раздел — из настройки Plezy «стартовая вкладка»; в офлайне — экран ошибки.
- «Назад» — цепочка Plezy (решено после проверки концепции): из контента — меню на текущем пункте; в
  открытом меню — переход на Главную; на Главной — «нажмите ещё раз для выхода». Закрыть меню без перехода — →.
  Расходится с дизайном («Назад из меню закрывает его»), потому что апстримные экраны сами отправляют «Назад»
  в меню; пересмотреть, когда экраны заменят S15, S16 и другие этапы.
- В офлайне корень вместо Главной — экран «Нет связи»: «Назад» из Настроек или Загрузок возвращает на него,
  на нём двойное «Назад» — выход.
- Апстримные экраны внутри оболочки могут выглядеть криво (отступы, свои вкладки, фон) — допускается до их
  замены. Обязательно: фокус не теряется, ← с первой колонки открывает наше меню.

Сохраняется поведение Plezy: запуск онлайн-служб при подключении, переход в офлайн и обратно, выбор профиля
при старте (без повторного вопроса), ссылки из лаунчера и Live TV, Watch Together, пульт-компаньон и ссылки
`plezytv://screen/...` (S5), проверка обновлений, обновление контента после долгого сна, смена профиля.

Не делаем: группировку библиотек по серверам в меню, группу «Скрытые» в меню, переключатель полного экрана
(только десктоп), новые экраны разделов.

## 3. Сценарии

- Включили TV, сервер доступен: стартовый раздел (по умолчанию Главная Plezy), фокус в контенте; ← из первой
  колонки раскрывает меню на текущем пункте; → или Назад закрывают его и возвращают фокус.
- Выбор «Фильмы» в меню: открывается апстримная библиотека «Фильмы».
- Скрытая библиотека: меню → «Ещё» → список по серверам → библиотека открывается.
- Сервер выключен при старте: экран «Нет связи с сервером», «Повторить» в фокусе; сервер поднялся, «Повторить» —
  обычное меню и стартовый раздел.
- Ссылка `plezytv://screen/library?...` по adb открывает нужную библиотеку, как в S5.
- Из лаунчера (канал «Продолжить») — сразу воспроизведение, как в Plezy.
- Назад в контенте раздела → меню; Назад в меню → Главная; на Главной подсказка, второе Назад — выход.
- Офлайн: из Настроек Назад → «Нет связи»; там двойное Назад — выход.

## 4. Допущения и риски

- Обвязку `MainScreen` придётся повторить в своём коде: она приватная в файле, который не правим. Риск —
  потерять какую-то обязанность; требования перечисляют их явно, приёмка проверяет на TV.
- Апстримные экраны зависят от `MainScreenFocusScope`; оболочка должна его предоставлять.
- Единого «выбранного сервера» в Plezy нет (объединяет все серверы профиля); «Выбрать другой сервер», вероятно,
  — переход к настройкам подключений. Уточнить в требованиях.
- Скорость оболочки на Mi Box 4 смотрим на телеке, отдельных замеров нет (S2 снят).
