# S16 — Сетка библиотеки: концепция

Этап проекта `docs/projects/plezy-tv/project.md`, S16. Профиль `full`.

> Проект — высокоуровневый план; его допущения проверяет этот flow. Сведения об апстриме ниже —
> из чтения кода агентом 2026-10-24 (`lib/screens/libraries/`), сборкой не проверены.

## Проблема и цель

На TV раздел библиотеки в оболочке S12 пока показывает апстримный `LibrariesScreen`. Он сделан под
телефон и не похож на дизайн. Цель — свой TV-экран библиотеки по макетам `02-library-*` и
`07-state-loading-library.png`. Он должен быстро работать с пульта на Mi Box 4 и уметь всё, что умеет
апстримный экран библиотеки. Пользователь — владелец трёх Android TV, управляет с пульта.

## Объём и решения

Решения пользователя 2026-10-24 (с поправками после проверки концепции):
- Вкладки — как в Plezy: **Библиотека / Рекомендуемое / Коллекции / Плейлисты**. Набор зависит от
  библиотеки, как у Plezy (у общей библиотеки с чужого сервера, например, только Библиотека и Плейлисты).
  В дизайне только первые три; плейлисты рисуем той же сеткой.
- **Группировка, сортировка и фильтры** — в правой панели из дизайн-системы (§6.4), собранной из пунктов
  настроек. Отдельного макета панели нет. Набор вариантов определяет Plezy, включая группировки
  (по сезонам, эпизодам, папкам — где Plezy их разрешает). Колонка букв ведёт себя по правилам Plezy для
  текущей сортировки и группировки.
- **Папки** — не вкладка, а группировка «по папкам», как в Plezy. Вместо сетки — список строк в стиле
  пунктов настроек: OK по папке открывает её содержимое, «Назад» — на уровень выше, OK по элементу
  открывает его.
- **«Обновить библиотеку»** на пустом экране только перезагружает данные, без скана на сервере.
- **«Ещё»** в шапке открывает правую панель с действиями Plezy для текущей библиотеки (скан файлов,
  анализ, обновление метаданных, очистка корзины — те, что Plezy показывает для этой библиотеки и
  сервера, с подтверждением и сообщением об ошибке) и пунктом **«Управление библиотеками»**: порядок и
  скрытие всех библиотек. После изменения боковое меню оболочки обновляется.
- **Вход с фильтром**: экран умеет открыться сразу с заданным фильтром (например, жанр из карточки
  фильма S8). S16 даёт этот вход; S7/S8 только вызывают его.
- **Музыка и фото**: для таких библиотек до S17 остаётся апстримный `LibrariesScreen`, как сейчас.
  Свой экран — для фильмов и сериалов.
- Вход в раздел без выбранной библиотеки (меню, ссылка `plezytv://screen/libraries`) — как в Plezy:
  последняя выбранная, иначе первая видимая; выбор запоминается в оболочке. Скрытая, удалённая или
  несуществующая библиотека и «все библиотеки скрыты» обрабатываются как в Plezy.
- Вкладка «Библиотека» — по дизайну: шапка с названием, кнопка сортировки «{порядок} · {count}», кнопка
  «Фильтры · {n}», сетка 6 колонок, колонка букв (`#`, А–Я или A–Z, пустые буквы пропускаются).
- Состояния: статичный скелетон, пусто, ошибка — по общим правилам `screens.md` §7.

Ограничения проекта: только TV, мобильные экраны и общий код апстрима не трогаем, большие файлы
апстрима не правим, производительность важна. Из дизайна берём только внешний вид. Если макет
противоречит возможностям Plezy, следуем коду.

Не делаем: свой экран и карточки для музыки и фото (S17), карточку фильма и страницу сериала
(S7/S8). Пока их нет, OK по элементу открывает существующий экран деталей Plezy.

## Типичные сценарии

1. Выбрал в меню «Фильмы» → видны шапка, вкладки и скелетон, затем сетка. Фокус на первом постере.
2. Листает сетку вниз: новые элементы подгружаются без остановки фокуса.
3. → из 6-й колонки → буква текущего элемента. Выбрал «М», OK → фокус на первом фильме на «М».
4. ↑↑ к кнопкам → «по названию» → правая панель → выбрал «по дате добавления» → сетка пересобрана,
   фокус на первом элементе. «Фильтры» → выбрал жанр → на кнопке «Фильтры · 1», число в шапке меняется.
5. Открыл фильм, вернулся «Назад» → фокус на том же постере, прокрутка на месте.
6. Вкладки «Рекомендуемое» (хабы библиотеки рядами), «Коллекции», «Плейлисты» (сетки). Группировка
   «по папкам» — список с переходом вглубь.
7. Пустая библиотека → текст и «Обновить библиотеку» в фокусе → перезагрузка.
8. Нет связи → экран ошибки с «Повторить», меню доступно.
9. «Ещё» в шапке → правая панель → «Сканировать файлы» → подтверждение → сообщение о запуске.
10. «Ещё» → «Управление библиотеками» → скрыл «Мультфильмы» → пункт пропал из бокового меню.
11. На карточке фильма OK по жанру «Фантастика» → библиотека с этим фильтром, «Фильтры · 1».
12. `plezytv://screen/libraries` без библиотеки → последняя выбранная; с несуществующим id — как в Plezy.
13. Выбрал в меню музыкальную библиотеку → апстримный экран, как до S16.

## Открытые вопросы и допущения

- Как выглядит «Рекомендуемое»: по смыслу это ряды хабов, как на главной S15. Предполагаем, что
  переиспользуем ряды S15.
- Сохраняются ли выбранные сортировка, фильтры и вкладка между заходами — как в Plezy; уточнить в
  требованиях.
- Скорость прокрутки большой сетки на Mi Box 4 — гипотеза, проверяется на устройстве.
