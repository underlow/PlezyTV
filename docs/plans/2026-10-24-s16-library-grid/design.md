# S16 — Сетка библиотеки: дизайн

Контракт — [requirements.md](requirements.md) (L1–L20, A1–A24). Сведения о коде — чтение 2026-10-24, не сборка.

## 1. Обзор

Для видео-библиотек оболочка S12 строит свой `TvLibraryScreen` в `lib/plezytv/tv_ui/library/`, для остальных —
апстримный `LibrariesScreen`, как сейчас. Данные, модели запроса, хранение настроек, группировки и логика
букв берутся из не-UI кода Plezy вызовом. Своё — контроллер настроек библиотеки, разреженный постраничный
источник, сетка, колонка букв, правая панель (общий компонент), список папок, действия над библиотекой.
Большие файлы апстрима не правятся.

## 2. Существующая система

- **Оболочка** `lib/plezytv/tv_ui/shell/tv_section_shell.dart` (TV-код): раздел библиотек строит
  `LibrariesScreen` с `onLibrarySelected`/`onLibraryOrderChanged`, маршрутизирует выбор через
  `LibraryLoadable.loadLibraryByKey` и обновление через `Refreshable`; меню строится из `LibrariesProvider` и
  `HiddenLibrariesProvider`, есть пункт «Ещё библиотеки».
- **Клиент** `lib/media/media_server_client.dart` — общий для Plex и Jellyfin/Emby: постраничный контент
  библиотеки, фильтры со значениями, сортировки, хабы, папки и их содержимое, обновление метаданных.
  Plex-действия (скан, анализ, корзина) — у клиента Plex.
- **Модели запроса** `lib/media/library_query.dart` (`LibrarySort`, `LibraryFilter`, `LibraryQuery`,
  `LibraryPage`), сборка запроса — публичная `libraryQueryFromSelection`.
- **Хранение** `StorageService`: вкладка, сортировка с направлением, фильтры, группировка по библиотеке и
  выбранная библиотека — в рамках профиля.
- **Группировки** `library_browse_grouping.dart`, **буквы** `library_alpha_bar_strategy.dart` и
  `alpha_jump_helper.dart` — без UI, вызываются как есть (`isPhone: false`).
- **Не вызывается снаружи:** обвязка запроса в приватных методах `library_browse_tab.dart` (2298 строк),
  действия над библиотекой в приватных функциях `library_management_sheet.dart`.
- **Компоненты S6/S15** в `lib/plezytv/tv_ui/components/`: постер, эпизод, скелетоны, вкладки, кнопки,
  пункт настроек, ряд, карточка «Все». Правой панели нет.
- **Ссылки S5** `docs/plezytv/dev-tools.md`: `screen/libraries`, `screen/library?id=`.

## 3. Архитектура

- **Переключатель раздела** (в оболочке): по виду выбранной библиотеки строит `TvLibraryScreen` или
  `LibrariesScreen` и передаёт активному `LibraryLoadable`/`Refreshable`. Вид определяет одно правило
  `isTvVideoLibrary` (фильмы, сериалы, общая библиотека) — его используют и переключатель, и вход L16.
- **`TvLibraryScreen`** — хост: выбор библиотеки (L2/L3) через хранилище Plezy и провайдеры, шапка, вкладки,
  одна активная вкладка, наложение правой панели, состояния L17–L19. Сообщает оболочке выбор (как
  `onLibrarySelected`). Режим L16 — тот же хост, открытый маршрутом поверх, без сообщения оболочке.
- **`TvLibraryController`** — один на текущую библиотеку и режим. Владеет настройками (вкладка, группировка,
  сортировка и направление, фильтры), списками сортировок и фильтров с сервера, стратегией букв и буквами,
  общим числом. Пишет настройки через интерфейс хранения: обычный — `StorageService`, L16 — в памяти.
- **`tv_library_query`** — копия обвязки запроса Plezy (~30 строк: группировка → тип, видео для общей
  библиотеки, виды по умолчанию, тип для списка сортировок, направление по умолчанию) со ссылкой на
  источник; дальше — вызов `libraryQueryFromSelection`.
- **`TvPagedSource<T>`** — разреженный кэш по индексам: известное общее число, загруженные страницы,
  страницы в полёте и неудачные, поколение для отмены. Используют вкладка «Библиотека», коллекции, плейлисты.
- **`TvPagedGrid`** — сетка с фиксированным размером ячейки и числом элементов = общее число. Незагруженные
  места — статичные фокусируемые заглушки, запрашивающие свою страницу. Колонки: 6 постеров, для группировки
  «по эпизодам» — 4 карточки эпизода 16:9 (решение пользователя). Помнит индекс в фокусе по вкладке.
- **`TvAlphaColumn`** — колонка букв поверх стратегии Plezy; переход вычисляет индекс, прокручивает к его
  строке, затем ставит фокус. Для Jellyfin/Emby — путь Plezy с префиксом-фильтром.
- **`TvRightPanel`** (`components/`, общий, для S9 тоже) — панель §6.4 со стеком страниц из пунктов
  настроек, «Назад» снимает страницу, с последней — закрывает и возвращает фокус на кнопку-якорь. Страницы
  библиотеки: сортировка (группировка, список, направление, сброс), фильтры (категории → страница значений
  по виду: несколько, диапазон, текст, переключатель; «Сбросить все»), «Ещё» (действия, «Управление
  библиотеками»), управление (порядок, скрытие).
- **Действия над библиотекой** — своя реализация (~100 строк, решение пользователя) на вызовах клиента и
  строках `t.libraries.*` Plezy, с тем же набором по серверу и подтверждением.
- **`TvFolderList`** — строки над папками клиента, стек уровней с запомненной строкой.
- **«Рекомендуемое»** — ряды S15 (`TvHorizontalRow`, `TvAllCard`) над хабами библиотеки.
- **Вход L16** — маршрут `TvLibraryScreen.filtered(библиотека, поле, значение)`; ссылка S5
  `plezytv://screen/library-filter?id=…&field=…&value=…` (ключи поля и значения сервера).

## 4. Состояние и владение

- Контроллер создаётся при выборе библиотеки, при смене библиотеки уничтожается (в памяти только текущий).
  Хост остаётся смонтированным при переходе на экран элемента, поэтому фокус и прокрутка сохраняются (L7).
- Любое изменение настроек увеличивает поколение источника: ответы старых поколений отбрасываются,
  кэш и запомненный фокус вкладки сбрасываются (L7, L11). Число в шапке — из первого ответа нового поколения.
- Неудачная страница помечается и снова запрашивается, когда её место снова строится (L19).
- События Plezy об изменении просмотра и удалении: просмотр — правка элемента в кэше; удаление —
  перезапрос страницы и фокус на соседний индекс (L8).
- Обновление L20 перезапрашивает загруженные страницы вокруг фокуса того же поколения; панель и стек папок
  не трогаются; фокус на элементе с тем же id, иначе на том же индексе.
- L14: изменения порядка и скрытия идут через провайдеры, на которые подписано меню оболочки.
- Фокус при загрузке (L17): хост ставит фокус на первую карточку, только если он всё ещё на выбранной вкладке.

## 5. Общие контракты

- **Хранение настроек:** загрузить / сохранить {вкладка, группировка, сортировка+направление, фильтры} для
  библиотеки. Обычная реализация пишет в `StorageService` (общее с Plezy), L16 — только в память.
- **Постраничный источник:** общее число (неизвестно до первого ответа), элемент по индексу или «нет»,
  запрос индекса, повтор, сброс с новым поколением, уведомление об изменённых страницах (без перестройки
  всей сетки).
- **Правая панель:** открыть с якорем и корневой страницей; страница — заголовок и пункты; закрытие
  возвращает фокус якорю.
- **`isTvVideoLibrary(library)`** — единственное правило L1.
- **Ссылка L16:** неизвестная или не-видео библиотека, неизвестное поле — экран не открывается, запись в лог
  `PlezyTV`.

## 6. Решения

- **D1 Обвязка запроса — копия.** Приватные методы виджета Plezy снаружи не вызвать; копируем ~30 строк в
  TV-код со ссылкой на источник и тестом на ожидаемые значения. Тест ловит изменения нашей копии, но не
  апстрима, поэтому проверка мержа апстрима (`plezytv-upstream.yml`) добавляет предупреждение в PR при
  изменении `library_browse_tab.dart`, `library_browse_grouping.dart`, `library_alpha_bar_strategy.dart`,
  `library_management_sheet.dart`. Отвергнуто: вынос из большого файла апстрима — нарушает правило проекта.
- **D2 Действия над библиотекой — своя реализация** (решение пользователя): у апстрима они приватны и с
  телефонными диалогами.
- **D3 Редакторы фильтров — свои страницы панели**, а не встраивание апстримных `filters/*` (сенсорная
  раскладка, плохой фокус). Значения фильтров — вызовом клиента; у Jellyfin/Emby фильтры грузятся после
  первой страницы, кнопка «Фильтры» до этого неактивна.
- **D4 Правая панель — общий компонент** в `components/`, чтобы S9 переиспользовал.
- **D5 Разреженный кэш** вместо дописываемого списка Plezy (`PagedMediaListState`): переход по букве в
  середину не должен грузить всё до неё.
- **D6 Отдельная ссылка L16**, а не параметры `screen/library` — та запоминает выбор и меняет меню.
- **D7 Переключатель внутри раздела оболочки**, без изменения модели разделов S12.
- **D8 Эпизоды** — 4 колонки карточек 16:9 (решение пользователя); стратегия букв считает по индексам,
  число колонок влияет только на строку прокрутки.

## 7. Потоки

1. **Вход (L2, L17).** Оболочка → переключатель → `TvLibraryScreen` берёт ключ из хранилища или первую
   видимую → контроллер читает настройки → шапка и вкладки сразу, фокус на вкладке → через 300 мс
   скелетон → первая страница: число в шапку, фокус на первую карточку, если он на вкладке.
2. **Прокрутка (L6, L19).** Строится место i → источник запрашивает страницу → ответ своего поколения
   заполняет страницу и уведомляет её ячейки; чужого — отброшен; ошибка — пометка, повтор при новом
   построении места.
3. **Буква (L10).** → из последней колонки → подсветка заморожена → OK на «М» → индекс по буквам сервера →
   прокрутка к строке → запрос страницы → фокус на индекс.
4. **Панель (L11).** Пункт сортировки → контроллер меняет настройки, сохраняет через интерфейс хранения
   (L16 — память) → новое поколение, число обновлено, фокус в панели → «Назад» → фокус на кнопке.
5. **L16.** Ссылка или вызов → проверка `isTvVideoLibrary` и поля → маршрут поверх с хранением в памяти,
   засеянным сохранённой группировкой и сортировкой и одним фильтром → «Назад» снимает маршрут, раздел
   оболочки не меняется.
