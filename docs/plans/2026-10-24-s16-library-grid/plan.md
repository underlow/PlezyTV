Контракт — [requirements.md](requirements.md) (L1–L20, A1–A24) и [design.md](design.md); они главнее плана.

## 1. Результат

На TV видео-библиотеки открываются своим `TvLibraryScreen`: шапка, вкладки, сетка с подгрузкой, колонка
букв, правая панель группировки, сортировки и фильтров, папки, «Ещё» с действиями и управлением
библиотеками, контекстное меню, состояния, вход с фильтром и его ссылка S5. Не-видео библиотеки — экран
Plezy, как раньше.

- Тексты — `TvStrings`; где у Plezy есть строка (`t.libraries.*`, сообщения действий) — строка Plezy.
- Размеры и цвета — `tv_tokens.dart` / `tokens.json`; раскладка — `design-system.md`, `screens.md` §2, §7,

- Производительность (Mi Box 4): ячейки сетки перестраиваются только при изменении своей страницы; без
  анимации прокрутки при переходах; декодирование картинок в размер карточки.
- Проверки каждой задачи: `dart format` изменённых файлов, `flutter analyze`, тесты своих файлов и

## 3. Задачи

### T1 — Правая панель
Результат: общий `TvRightPanel` в `components/` (design §3, §5, D4) для L11, L13, L14.
- Открывается поверх экрана с якорем и корневой страницей; страница — заголовок и пункты (`TvSettingsItem`
  и его варианты: выбор одного, отметка нескольких, переключатель, переход на страницу, кнопка действия,
  перемещение пункта вверх/вниз для порядка). Переход на страницу кладёт её в стек; «Назад» снимает
  страницу, с корня — закрывает и возвращает фокус якорю. Можно обновить содержимое открытой страницы.
- Внешний вид — §6.4 дизайн-системы. Без знания о библиотеках.
- Проверка: тест виджета — открытие, переход вглубь, «Назад» дважды → фокус на якоре; обновление
  содержимого без потери фокуса. Ловит потерю фокуса на телевизоре после закрытия.

### T2 — Постраничный источник, сетка, колонка букв
Результат: в `components/` (или `library/`, если компонент знает о `MediaItem`) — `TvPagedSource<T>`,
`TvPagedGrid`, `TvAlphaColumn` по design §3–§5 (D5). Без знания о сервере: источник получает функцию
загрузки страницы.
- Источник: общее число, элемент по индексу, запрос индекса (страницей), неудачные страницы повторяются при
  новом запросе, поколение (ответы старых отбрасываются), обновление без очистки, пометка страниц
  устаревшими, удаление элемента со сдвигом (число − 1, следующие страницы устаревшие), уведомление по
  страницам.
- Сетка: число колонок и размер ячейки — параметры (6 постеров, 4 эпизода 16:9); число мест = общее
  число; незагруженные — статичные фокусируемые заглушки; узлы фокуса только у построенных; переход к
  индексу `jumpTo` + ожидающий фокус + поколение переходов (design §3); запоминает индекс в фокусе;
  обработчики выхода за края (↑ из первой строки, ← из первой колонки, → из последней) отдаются наружу.
- Колонка букв: буквы с признаком «пустая», подсвеченная буква — извне, заморожена пока колонка в фокусе;
  ↑/↓ пропускают пустые; OK и ← — наружу.
- Проверка: тесты источника (поколение, ошибка и повтор, удаление со сдвигом, обновление с якорем по id);
  тест сетки на 3000 элементов — удержание ↓ не теряет фокус, переход к индексу 2500 ставит фокус на
  него после загрузки; тест колонки — пустые пропускаются, подсветка не меняется при ↑/↓. Ловит прыжок
  фокуса и загрузку всех страниц до цели.

### T3 — Контроллер библиотеки
Результат: `TvLibraryController`, `tv_library_query`, интерфейс хранения с реализациями `StorageService` и
памятью (design §3–§5, D1). Без UI.
- Загружает и сохраняет настройки (вкладка, группировка, сортировка+направление, фильтры), списки
  сортировок и фильтров с сервера (у Jellyfin/Emby — фильтры после первой страницы, признак «грузятся»),
  стратегию и буквы Plezy с `isPhone: false`, префикс Jellyfin/Emby; собирает запрос через копию обвязки
  и `libraryQueryFromSelection`; выдаёт источник для вкладки «Библиотека»; меняет поколение при любом
  изменении; подписан на события просмотра, удаления, изменения библиотеки (design §4).
  Стек папок (design §3) — тоже здесь.
- Копия обвязки — со ссылкой на файл и метод Plezy в комментарии.
- Проверка: тесты обвязки на ожидаемые значения Plezy (группировка → тип, общая библиотека → видео,
  виды по умолчанию для «все», тип списка сортировок, направление по умолчанию, `canGroupByFolders`);
  сохранение пишет в `StorageService` и читается так же, как Plezy читает (A9); режим памяти не пишет
  (A20); устаревший ответ сортировок другой библиотеки отброшен.

### T4 — Экран библиотеки: вкладка «Библиотека» и состояния
Зависит от T2, T3. Результат: `TvLibraryScreen` для выбранной библиотеки — L4–L10, L17–L20 и OK/меню L8.
- Шапка (название, кнопки сортировки, «Фильтры», «Ещё» — пока как якоря; панели подключают T5, T7),
  вкладки по набору Plezy (L5), сетка с колонкой букв (L9 — по стратегии), навигация L7, OK
  `navigateToMediaItem`, долгий OK и «Меню» — `MediaContextMenu` (как `tv_home_screen.dart`),
  возврат на тот же элемент.
- Состояния: скелетон через 300 мс, фокус по L17; пусто (оба варианта L18); ошибка L19 с «Повторить»;
  пустая вкладка L15.
- Обновление L20 по интерфейсам оболочки и событиям (design §4); экран реализует интерфейсы, которые
  передаст переключатель (T8).
- Колонка букв: у Plex — переход сетки; у Jellyfin/Emby — OK по букве меняет префикс контроллера.
- Вкладки кроме «Библиотека» — заглушки, их делает T6.
- Проверка: тесты виджета с подделкой клиента — A7 (число), A10–A15, A21–A24; возврат с экрана элемента
  (A12); обновление сохраняет фокус; обновление во время перехода по букве не теряет ожидающий фокус;
  событие удаления элемента в фокусе → после возврата фокус на соседнем (i, у последнего — i−1), не на
  заглушке; Jellyfin/Emby — буква меняет префикс и число.

### T5 — Сортировка, фильтры, группировка, папки
Зависит от T1, T4. Результат: L11, L12.
- Кнопка сортировки открывает панель: группировка, сортировки сервера, направление, «Сбросить»; кнопка
  «Фильтры» — категории и страницы значений по виду (несколько, диапазон, текст, переключатель),
  «Сбросить все», число полей на кнопке. Своего ввода текста в TV-коде нет: текстовый фильтр — поле на
  странице панели с системной клавиатурой Android TV; после закрытия клавиатуры фокус на этом поле.
  Своя экранная клавиатура из дизайна — работа S11 (поиск). Изменения применяются сразу (L11).
- Jellyfin/Emby: кнопка «Фильтры» неактивна, пока контроллер сообщает «фильтры грузятся».
- Группировка «по папкам» — `TvFolderList` над стеком контроллера: L12 и возврат в ту же папку/строку,
  ошибка уровня с «Повторить».
- Проверка: A16, A17, A7, A22; «Назад» из панели — фокус на кнопке, ↓ — первый элемент; папки — «Назад» на
  уровень выше; пустая папка; обновление (L20) при открытой панели и внутри папки — панель и папка на месте;
  «Фильтры» неактивна, пока фильтры Jellyfin/Emby грузятся.

### T8 — Оболочка, выбор библиотеки, вход с фильтром, ссылка
Зависит от T4. Результат: L1–L3, L16, проверка мержа апстрима.
- `TvLibrariesSwitch` в разделе библиотек оболочки (design §3): разрешение ключа, состояния «нет
  библиотек» / «все скрыты» (кнопка открывает «Управление библиотеками» T7, если T7 ещё нет — делает T9),
  выбор `TvLibraryScreen` или `LibrariesScreen`, пересоздание при смене, передача интерфейсов оболочки.
- Маршрут `TvLibraryScreen.filtered` с хранением в памяти; цель ссылки в `lib/plezytv/screen_links/` с
  порядком проверок design §3; описание в `docs/plezytv/dev-tools.md`. Парсер сейчас берёт имя цели из
  имени значения перечисления и принимает только `id`, `server`, `q`; `id` — только цифры. Путь
  `library-filter` сопоставляется с отдельным значением перечисления явно; только для этой цели
  допустимы `field` и `value` (обязательны, вместе с `id`, `server` — необязателен), для остальных целей
  лишние параметры по-прежнему отклоняются; правило `id` не меняется (Plex).
- `plezytv-upstream.yml`: предупреждение в PR по списку файлов D1. Правила подключения экрана — в
  `docs/plezytv/tv-ui.md`.
- Проверка: A1–A6, A20 — через настоящий путь раздела библиотек оболочки (не через
  `sectionBuilderForTesting`, который подменяет его целиком) с настоящими провайдерами и подделкой клиента;
  ссылка `screen/library?id=` выбирает библиотеку через переключатель; переход видео → музыка → видео в меню
  пересоздаёт экран. Тесты разбора ссылки: без `field` или `value` — отказ; `field` у других целей — отказ;
  маршрутизация: неизвестная библиотека, не-видео, неизвестное поле → экран не открыт. Существующие тесты
  оболочки и ссылок проходят. Пути из списка D1 в `plezytv-upstream.yml` существуют (`git ls-files`).
