# S27 — Исправления интерфейса TV: план

Контракт: [problem.md](problem.md), [specification.md](specification.md). План подтверждён пользователем 2026-11-06.

## Общие правила

Свой код — в `lib/plezytv/`. Правки вне него только в `media_context_menu.dart`, `media_navigation_helper.dart`,
`appearance_settings_screen.dart`. Правила форка: `docs/projects/plezy-tv/project.md`, `docs/plezytv/tv-ui.md`.

Проверки каждой задачи:

- `.tools/flutter/bin/flutter analyze` по изменённым файлам (полный падает на `packages/wakelock_plus`, это известно).
- `.tools/flutter/bin/flutter test test/plezytv/` (известны 2 датозависимых падения Live TV).
- `git diff --stat main...HEAD -- lib/ ':!lib/plezytv/'`: только три файла выше.
- Тесты с изменёнными ожиданиями — только из раздела 4 спецификации, перечисляются в отчёте. Поведенческие тесты не ослаблять.

На устройстве разработчик T1–T9 ничего не проверяет: вся приёмка в T10. Цена: проблемы раскладки вскроются позже.

Одна задача — один коммит в ветке `flow/s27-tv-ui-fixes`.

## T1. Меню (R1, R2)

Вход: `lib/widgets/media_context_menu.dart`, `lib/plezytv/tv_ui/tv_ui.dart`. На TV один «View details» для видео-карточек;
`TvUi.detailSubjectOf(context)` возвращает сервер и id открытой страницы (`TvShowScreen`, `TvMovieScreen`), пункт скрыт для самой
страницы и её сезонов и эпизодов. `_navigateToSeries` не менять. Сохранить: телефон без изменений, пункты Continue.

Тесты (меню на TV и на телефоне): TV-эпизод в обычном ряду — «View details» есть, «Go to series» нет; своя страница — нет пункта;
чужой сериал и тот же id на другом сервере — есть; телефон — прежний набор. Ловят возврат «Go to series» и пропажу пункта на чужой
карточке.

## T2. Правило OK (R3, R4)

Вход: `lib/utils/media_navigation_helper.dart`, `lib/screens/settings/appearance_settings_screen.dart`. На TV эпизод при `!isOffline
&& !playDirectly` открывает страницу независимо от `episodeAction`. `continueWatchingAction`, клипы, ряд эпизодов на странице сериала
(он идёт через `_play`) и кнопка Play на пульте не меняются. Episode Action не показывается на TV, значение не трогается.

Тесты (`navigateToMediaItem` и экран настроек; `test/utils/media_navigation_helper_test.dart`): TV обычный ряд → страница;
`playDirectly` с обоими значениями `continueWatchingAction`; офлайн и клип → запуск; телефон по `episodeAction`; настройка скрыта
только на TV. Ловят поломку экрана загрузок и мобильного режима.

## T3. Ряды (R8)

Вход: `components/tv_horizontal_row.dart`. Минимальный сдвиг вместо прыжка; правый отступ списка `safeX`; `hasScrolled` убрать;
`reduced` без анимации. Сохранить: память карточки и смещения, поиск следующей доступной карточки (`_seek`).

Тесты (виджет ряда: `tv_horizontal_row_test`, `tv_horizontal_row_home_test`): проход до края — смещения нет, шаг дальше — сдвиг на
одну карточку и виден край следующей; конец — последняя у правого края; обратно — без прыжка; восстановление из памяти. Ловят прыжок
на экран и уезд последней карточки.

## T4. Подпись сервера (R7)

Вход: `home/tv_home_model.dart`, `home/tv_home_screen.dart`, `components/tv_horizontal_row.dart`. Параметр ряда `source` необязателен,
остальные экраны его не передают.

Тесты (модель): один сервер — без подписи; два — с именем своего сервера; Continue и ряд без сервера — без подписи; второй сервер
пришёл позже — подпись появилась. Ловят подпись не того сервера и подпись при одном сервере.

## T5. Hero (R5, R6)

Вход: `home/tv_home_screen.dart`, `components/tv_hero.dart`, `library/tv_library_extra_tab.dart`, `tv_tokens.dart`. Высоту считает одна
функция от доступной области, режим compact удаляется, слот ряда на Home равен постерному. Recommended считает от своей доступной
области, поэтому T7 не требует правок высоты.

Тесты (`tv_layout_geometry_test`, `tv_hero_test`, `tv_home_screen_test`, `tv_library_extra_tab_test`): Home и Recommended на 1920×1080,
1280×720, 1024×768, 2560×1080 — нет переполнения, низ ряда на экране; высота hero не меняется при переходе с первого на третий ряд;
под музыкальным рядом следующий не виден. Ловят возврат сжатия и обрезанный ряд.

## T6. Панель фильтров (R13, R14)

Вход: `library/tv_library_panels.dart`, `library/tv_library_controller.dart`. Быстрый выбор по разделу «Фильтры» спецификации;
сохранение остаётся в контроллере.

Тесты (`tv_library_panels_test`): выбор Unwatched, затем Unmatched, затем All при активном жанре; нет поля — нет пункта; дублей ниже
нет; другой логический фильтр остаётся Yes/No; `unwatchedLeaves` считается Unwatched; сохранённый `No` виден в счётчике и снимается.
Ловят потерю соседних фильтров и потерю старого значения.

## T7. Шапка библиотеки (R15–R18)

Зависит от T5 и T6. Вход: `library/tv_library_screen.dart`, `library/tv_library_panels.dart`. `TvTabs` не менять. Новый виджет строки
Browse; группировка в своей панели; сброс Sort работает как раньше (включая группировку).

Тесты (`tv_library_screen_test`, `tv_library_extra_tab_test`, `tv_library_panels_test`): строка только на Browse; один вариант
группировки — кнопки нет; `Clear` только при активных фильтрах и сбрасывает сразу; сброс Sort возвращает группировку; фокус сетка →
строка → вкладки и обратно, влево с первого элемента — меню; сетка не ниже 200 px. Ловят потерю пути фокуса и сброса.

## T8. Вкладка сезона: нижние ряды (R12)

Вход: `show/tv_show_screen.dart`. Нижние ряды общие для всех вкладок; навигация клавишами, прокрутка и компактная шапка работают на
всех вкладках. Шаг до появления кнопок T9: фокус вкладки → эпизоды → нижние ряды. Сохранить: Back на «Сериал», фокус при входе на серию.

Тесты (`tv_show_screen_test`): вниз и вверх через ряды; ряда нет — нет пустой остановки; компактная шапка при прокрутке; Back на
вкладку «Сериал». Ловят ломку навигации вкладки «Сериал».

## T9. Вкладка сезона: кнопки (R9–R11)

Зависит от T8. Вход: `show/tv_show_screen.dart`, `show/tv_show_actions.dart`, новый `show/tv_episode_actions.dart`. Кнопка скачивания
выносится в общий виджет. Один сезон без изменений.

Тесты (`tv_show_screen_test`, `tv_show_actions_test`): без прогресса `Play`, с прогрессом `Continue` и `С начала`; переход на новую серию
и сразу вверх (без ожидания таймера) — кнопка запускает новую серию; после запуска с кнопки фокус в ряду эпизодов; вкладка «Сериал»
скачивает сериал, а кнопка серии — серию; один сезон без кнопок серии. Ловят запуск устаревшей серии и потерю фокуса.

## T10. Приёмка и документы

Зависит от T1–T9. Dev-сборка на Xiaomi, примеры A1–A20 спецификации. Новых автотестов нет. Отчёт: что запущено, замеры, скриншоты вне
репозитория (на них библиотека пользователя), реальные имена полей Plex, сохранение фильтров (R14), умещаются ли кнопки сезона,
Back. Найденное на устройстве чинится здесь или выносится на решение. Обновить `docs/plezytv/tv-ui.md`: убрать «accepted gap», описать
правило OK, высоту hero, ряды, строку Browse, вкладку сезона.

Сборка `com.underlow.plezytv.dev` не установлена: при первой установке нужен вход пользователя в аккаунт. Рабочий PlezyTV не трогать.
Xiaomi `<xiaomi-tv>`, 1920×1080, 32 бит, режим `reduced`. Адрес меняется (на 2026-11-06 `<tv-ip>:5555`): проверять модель перед
действиями. TCL только после вопроса пользователю. Видео на скриншот не попадает (белый кадр).
