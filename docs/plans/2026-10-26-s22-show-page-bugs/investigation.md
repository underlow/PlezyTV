# S22 — Страница сериала: название эпизода и фокус

Проект: `docs/projects/plezy-tv/project.md`, этап S22. Источник — находки 2 и 3 S20
(`docs/plans/2026-10-26-s20-tv-user-review/investigation.md`).

## 1. Отчёт

На Xiaomi (2026-10-26), сериал Slow Horses (один сезон, 6 эпизодов):

- B1. Вкладка сезона: в шапке над рядом эпизодов «S6 E2 · Slow Horses», на карточке эпизода «S6 E2 · Daddy
  Issues». Ожидается название эпизода.
- B2. Вкладка «Show»: фокус на постере сезона в ряду «Seasons»; стрелка вниз ничего не делает (дважды), ряды
  «Cast» и ниже недоступны с пульта. Ожидается: вниз — на следующий ряд, страница прокручивается к нему.

## 2. Воспроизведение

Скриншотами на телевизоре, `adb input keyevent`. Ограничение: проверен один сериал с одним сезоном.

## 3. Причина

- B1. `lib/plezytv/tv_ui/show/tv_show_screen.dart` (~строка 911) передаёт в `TvStrings.episode` `title:
  episode.displayTitle`; `MediaItem.displayTitle` для эпизода возвращает `grandparentTitle` — название сериала.
  Совпадение с названием сезона в отчёте случайно (сезон назван так же). Нужно название эпизода (`title`).
  Проверить другие места TV-интерфейса, где для эпизода вызывается `displayTitle` вместо названия эпизода
  (hero, экран после просмотра, панель плеера) и где это ошибка.
- B2. Не установлена. Вниз из ряда кнопок обрабатывается вручную (`_contentKeys`), из ряда «Seasons» — нет; дальше
  работает обход фокуса Flutter, и ряд «Cast» не находится. Установить причину по коду и тестом.

## 4. Исправление и регрессии

- B1: шапка эпизода показывает «S<сезон> E<номер> · <название эпизода>»; при скрытии спойлеров — как сейчас.
- B2: на вкладке «Show» из любого ряда вниз — на следующий видимый ряд (Seasons → Cast → … → последний), вверх —
  на предыдущий, из первого ряда под кнопками — на кнопки; страница прокручивается к ряду в фокусе. Вниз на
  последнем ряду — ничего. Работает и для сериала без сезонов (flattened), и без каста.
- Сохранить: вверх из контента — на вкладки, «Назад», выбор сезона по OK, поведение вкладок сезонов.
- Проверки: виджет-тесты на B1 (название эпизода в шапке) и B2 (вниз из Seasons фокусирует Cast; дальше по рядам);
  `flutter analyze`, тесты `test/plezytv/`.
