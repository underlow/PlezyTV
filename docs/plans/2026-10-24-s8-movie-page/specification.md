# S8 — Карточка фильма: спецификация

Проект: `docs/projects/plezy-tv/project.md`, этап S8. Запрос этапа: «Свой экран: жанры, режиссёр, единый блок
оценок, кнопка с текстом. После S3. Макет — `docs/design/screens.md` и PNG; приёмка по скриншоту.»
Макеты: `docs/design/screens/03-movie-focus-play.png`, `03-movie-scrolled-cast-similar.png`, раздел 3 `screens.md`.

> Предпосылки проекта не проверены заранее (см. предупреждение в проекте). Ниже — то, что проверено в коде.

## 1. Цель и границы

На TV онлайн-фильм открывается своим экраном PlezyTV вместо экрана деталей Plezy, по макету `03-movie-*`,
с функциональностью Plezy. Входит: экран, подключение через существующий хук S7, обновление после действий.
Не входит: офлайн-фильмы и телефон (остаются на экране Plezy); переход по жанру в отфильтрованную библиотеку;
выбор аудио и субтитров до запуска (его нет в Plezy, это S9); изменения в больших файлах апстрима.

## 2. Требования

- **R1 Маршрут.** На TV при включённом TV UI онлайн-элемент `MediaKind.movie` из `navigateToMediaItemDetails`
  открывает свой экран; офлайн, телефон и прочие типы — как сейчас. Прямой запуск (`playDirectly`) не меняется.
  Маршрут возвращает `true`, если состояние просмотра изменилось, как маршрут Plezy. Экраны фильмов
  складываются в стек (фильм из «Похожих» открывает новый экран; «Назад» возвращает по одному). Принятый
  пробел: фильм, открытый изнутри экранов Plezy прямым вызовом `mediaDetailRoute`, остаётся на экране Plezy.
- **R2 Шапка.** Сверху вниз: логотип (иначе название; издание `editionTitle` — подзаголовком, если есть);
  год · длительность · возрастной рейтинг; жанры метками (не фокусируются) и «Режиссёр: …» (если есть);
  оценки как в Plezy, включая оценки сообщества; технические чипы из меток качества Plezy для версии, которая будет воспроизведена
  (запомненный выбор Plezy, иначе первая); описание 4 строки
  (скрывается по правилу спойлеров Plezy). Пустые части не показываются. Фон и подкраска — из backdrop фильма.
- **R3 Главная кнопка с текстом:** «Смотреть», «Продолжить · осталось {t}» при прогрессе, «Пересмотреть» для
  просмотренного без прогресса; запускает воспроизведение как Plezy (с места остановки). При нескольких версиях
  и онлайн-сервере рядом сегмент выбора версии (как в Plezy).
- **R4 Остальные кнопки** с условиями видимости Plezy: «Трейлер» (если найден), «В список» (если есть источники
  watchlist, с выбором источника), «Просмотрено»/«Не просмотрено», «Скачать» (кроме Apple TV), «Ещё». Пока состояние списка грузится, кнопка «В список»
  неактивна, как в Plezy.
  Скачивание: новая загрузка и удаление готовой — штатным потоком Plezy; незавершённая, в очереди, на паузе
  или ошибочная — открывает экран «Загрузки» (как S7).
- **R5 «Ещё»** открывает контекстное меню Plezy для фильма (с начала, версия, сведения о файле, удаление с
  сервера и прочее по условиям Plezy).
- **R6 Нижние ряды:** «В ролях» (OK — фильмография), «Трейлеры и дополнительно» (OK — воспроизведение),
  связанные хабы сервера («Похожие» и др.; OK — обычная навигация и меню). Пустые ряды не показываются.
- **R7 Техническая информация** внизу: студия, аудио, субтитры, файл (разрешение · кодек · размер) из той же
  версии, что и чипы R2, без дополнительного запроса (данные потоков и размер из уже загруженных метаданных,
  Plex и Jellyfin); отсутствующие поля не показываются, блок без данных скрыт.
- **R8 Фокус и прокрутка.** При открытии фокус на главной кнопке. ↓ с кнопок — к первому ряду, далее по рядам;
  ↑ из первого ряда — на последнюю кнопку в фокусе. При уходе фокуса ниже кнопок страница прокручивается,
  шапка уходит и остаётся строка «название · год · длительность · возраст». Прокрутка анимируется, на слабых
  устройствах (`DevicePerformance.isReduced`) — без анимации. «Назад» — предыдущий экран.
- **R9 Обновление.** После плеера, отметки просмотра, изменения списка, действий меню метаданные и кнопки
  обновляются; события просмотра от других экранов применяются. Удаление фильма с сервера закрывает экран;
  удаление только загрузки экран не закрывает. Ошибка загрузки полных метаданных — показываем переданные данные. Если сервер сообщает, что фильма нет
  (удалён), экран ведёт себя как Plezy: закрывается, а если это первый маршрут — показывает состояние
  «недоступно».
- **R10 Загрузка:** до прихода полных метаданных — шапка из переданных данных и скелетоны рядов.

## 3. Дизайн

- **Подключение.** `TvUi` получает ветку фильма рядом с сериалом внутри существующего синхронного lookup (расширить проверку
  типа или общий lookup деталей, которому он делегирует), так что `media_navigation_helper.dart` не меняется. Остальное — в `lib/plezytv/tv_ui/movie/`.
- **Контроллер фильма** владеет данными: `fetchItemWithOnDeck`, оценки сообщества, extras, связанные хабы,
  применение событий просмотра, флаг «изменилось» для результата маршрута. Общие с `TvShowController` части
  (загрузка метаданных, extras, хабов, оценок, поиск трейлера) можно вынести в общий модуль, если это не меняет
  поведение S7; иначе — переиспользовать функции вроде `tvShowPrimaryTrailer`. Решает исполнитель плана.
- **Экран** владеет фокусом, памятью последней кнопки, прокруткой и сжатой шапкой; строится из компонентов S6
  (`TvButton`, `TvChip`, `TvRatings`, `TvHorizontalRow`, карточки, скелетоны, `TvTinted*`, `TvTheme`).
- **Действия** — только публичные помощники Plezy: `navigateToVideoPlayerWithRefresh`, `promptAndPlayVersion`,
  `WatchActions`, `showWatchlistSourceChooser`/`mutateWatchlistMembership`, `queueDownloadWithFeedback`,
  `MediaContextMenu`, `navigateToPersonMedia`, `buildMediaQualityLabels`, `mediaRatingsFor`/`withCommunityRatings`,
  `DeletionNotifier`, `WatchStateNotifier`. Приватные обработчики `media_detail_screen.dart` не копируем
  сверх необходимого; скопированную логику отмечаем в предупреждении апстрим-мержа, как S7 D2.
- **Тексты** — английские константы `TvStrings`, как в S7/S15/S16. Время «осталось» — форматтер Plezy.
- **Документация:** раздел S8 в `docs/plezytv/tv-ui.md`.

## 5. Согласование

Подтверждено пользователем 2026-10-24: текстовая главная кнопка с сегментом версии; все кнопки Plezy по их
условиям; «Ещё» — контекстное меню Plezy; жанры без перехода; блок технической информации
(уточнено после ревью: описывает ту же версию, что будет воспроизведена — запомненную Plezy, иначе первую).
Профиль medium; Codex не участвует. Мелкие решения реализации (общий модуль с S7, точная форма lookup) делегированы.
