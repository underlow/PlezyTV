# S8 — Карточка фильма: план

Контракт: `specification.md` (R1–R10, A1–A20). Checkout `/Users/underlow/Projects/PlezyTV`, ветка
`flow/s8-movie-page`. Правила экранов — `docs/plezytv/tv-ui.md`; образец — S7 (`lib/plezytv/tv_ui/show/`,
`test/plezytv/tv_ui/show/`, включая `fake_media_server_client.dart`).

## 1. Подход

Новый модуль `lib/plezytv/tv_ui/movie/`:
- `tv_movie_logic.dart` — чистые функции: текст главной кнопки (Смотреть / Продолжить · осталось {t} /
  Пересмотреть), индекс версии для показа (запомненный выбор Plezy `media_version_preference.dart`, иначе 0),
  строки технической информации R7 (студия, аудио, субтитры, файл) из `mediaVersions[i].parts[*].streams`,
  `videoResolution`, `videoCodec`, `sizeBytes`; тексты в `TvStrings`.
- `tv_movie_controller.dart` — `ChangeNotifier` по образцу `TvShowController` без сезонов: `fetchItemWithOnDeck`,
  оценки сообщества, extras, связанные хабы, кандидаты watchlist, события просмотра, `watchStateChanged`,
  признак «удалён» (сервер вернул null / событие удаления), ошибка с откатом к переданным данным.
  Общий код с `TvShowController` выносить только если поведение S7 и его тесты не меняются; иначе
  переиспользовать функции (`tvShowPrimaryTrailer`).
- `tv_movie_screen.dart` (+ при необходимости `tv_movie_actions.dart`) — раскладка по `03-movie-*.png`,
  фокус, прокрутка со сжатой шапкой, действия через публичные помощники Plezy (список в спецификации §3),
  закрытие при удалении и результат маршрута.

Подключение (R1): `TvUi.showDetailRoute` строит маршрут и для онлайн `MediaKind.movie` → `TvMovieScreen`,
общий fade-переход; `media_navigation_helper.dart` и другие файлы апстрима не меняются.

## 2. Задачи

### T1 — Логика и контроллер фильма
**Результат:** `tv_movie_logic.dart`, `tv_movie_controller.dart`, тесты в `test/plezytv/tv_ui/movie/`.
**Вход:** спецификация R2, R3, R7, R9, R10. **Зависимости:** нет.
**Сохранить:** поведение и тесты S7 (`test/plezytv/tv_ui/show/`).
**Проверки:**
- unit-тесты текста кнопки (прогресс, без прогресса, просмотрен; формат времени Plezy) — ловят неверный выбор
  состояния (A3, A4);
- индекс версии: запомненная вторая версия → 1, без предпочтения → 0 (A15);
- строки R7 на фикстурах Plex и Jellyfin-подобных данных, пустые поля скрыты (A12, A16);
- контроллер с фейковым клиентом: загрузка, откат при ошибке, null → удалён (A17), событие просмотра меняет
  элемент и `watchStateChanged`, повторный `refresh` не гонится со старым ответом;
- `flutter analyze` чисто, `flutter test test/plezytv/` проходит.

### T2 — Экран и маршрут
**Результат:** `TvMovieScreen` (и действия), ветка фильма в `TvUi.showDetailRoute`, widget-тесты.
**Вход:** спецификация целиком, T1, макеты `docs/design/screens/03-movie-*.png`, `docs/design/screens.md` §3.
**Зависимости:** T1.
**Сохранить:** маршрут сериала и офлайн/телефон-фолбэк; без изменений в файлах апстрима.
**Проверки (widget-тесты на `pumpTvWidget`, фейковый клиент):**
- `tv_ui_test`: онлайн-фильм → маршрут фильма; офлайн, `enabled: false`, эпизод → null (A1, A2);
- шапка: части есть/нет, спойлеры, чипы по выбранной версии (A11, A15, A19);
- кнопки: видимость по условиям (трейлер, список неактивен при загрузке, скачать скрыт на Apple TV, сегмент
  версии только при >1 версии онлайн) (A5, A20); «Ещё» открывает `MediaContextMenu` (A7);
- фокус: при открытии на главной кнопке; ↓/↑ между кнопками и рядами с памятью кнопки; сжатая шапка;

- пустые ряды скрыты (A9); удаление закрывает экран (A10, A17); «Назад» возвращает `true` после смены
  просмотра (A6, A18); обновление после возврата из плеера (A13 — через фейковый колбэк обновления);
- `flutter analyze`, `flutter test test/plezytv/`.
