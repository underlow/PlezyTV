# S7 — Страница сериала: концепция

Этап проекта `docs/projects/plezy-tv/project.md`, S7. Профиль `full`. Реализация — Codex.

> Проект — высокоуровневый план; его допущения проверяет этот flow. Сведения об апстриме — из чтения
> кода 2026-10-24, сборкой не проверены.

## Проблема и цель

На TV сериал открывается апстримным `MediaDetailScreen` — общим экраном деталей Plezy, не похожим на
дизайн и не похожим на старый Plex. Цель — свой TV-экран сериала по макетам `04-show-tab-show.png` и
`04-show-tab-season.png` (`docs/design/screens.md` §4): шапка про сериал, вкладки «Сериал / Сезон N», постеры
сезонов, эпизоды кадрами с названиями. Функции — не меньше, чем у страницы сериала Plezy. Пользователь —
владелец трёх Android TV, управляет с пульта.

## Объём и решения

Решения пользователя 2026-10-24:
- **Кнопки** — все кнопки Plezy в ряду, в стиле макета: главная (смотреть/продолжить/пересмотреть),
  трейлер (если есть), перемешать, список (watchlist), просмотрено, скачать, «⋯» (меню Plezy). Набор и
  доступность — как у Plezy для этого сервера.

Решения координатора 2026-10-24 (пользователь делегировал все решения на время отсутствия):
- Свой экран — только для сериала на TV в онлайн-режиме. Сезон и эпизод, ведущие на детали сериала
  (OK по сезону, «Перейти к сериалу» из меню, «Продолжить просмотр» с настройкой «открывать детали»),
  открывают свой экран на вкладке нужного сезона с фокусом на нужном эпизоде — как макет.
- **Офлайн** (из Загрузок) и фильм остаются апстримными: офлайн — редкий путь на TV, фильм — этап S8.
  Точку подключения экрана деталей выбирает этот этап так, чтобы S8 добавил фильм рядом.
- Под сезонами — ряды «В ролях», «Дополнительно» (экстры) и «Похожие», если у Plezy они есть для этого
  сервера; порядок и наличие — как в Plezy, вид — ряды S15.
- Сезон «Спецвыпуски» и сериалы с одним сезоном — по правилам Plezy (вкладки по реальному списку
  сезонов сервера).
- Название эпизода сохраняется под кадром всегда (цель проекта: «названия эпизодов сохранить»).

Ограничения проекта: только TV, мобильные экраны и общий код апстрима не трогаем, большие файлы апстрима
(`media_detail_screen.dart`, `media_context_menu.dart`) не правим, производительность важна. Из дизайна
берём только внешний вид; где макет противоречит возможностям Plezy, следуем коду.

Не делаем: карточку фильма (S8), страницу эпизода, офлайн-вариант, свою панель плеера (S9).

## Типичные сценарии

1. В библиотеке OK по сериалу → шапка с логотипом, строка «годы · сезоны · эпизоды · возраст · студия»,
   вкладки, жанры и оценки, описание, кнопки; фокус на главной кнопке «Продолжить S1 E3 · осталось 35 мин».
2. OK по главной кнопке → плеер с места остановки. Вернулся → кнопка показывает следующую серию.
3. ↓ к «Сезоны» → OK по «Сезон 2» → вкладка «Сезон 2», фокус на первом непросмотренном эпизоде.
4. На вкладке сезона листает эпизоды → шапка и фон меняются под эпизод в фокусе. OK → плеер.
5. «Назад» на вкладке сезона → вкладка «Сериал»; ещё «Назад» → предыдущий экран, фокус там на сериале.
6. Из «Продолжить просмотр» эпизод с настройкой «открывать детали» → экран сериала на его сезоне и эпизоде.
7. Кнопки «просмотрено», «в список», «скачать», «⋯» → действие Plezy, состояние экрана обновляется.
8. Нет связи → экран ошибки с «Повторить».
9. Сериал из Загрузок без сети → апстримный экран, как сейчас.

## Открытые вопросы и допущения

- Скорость смены шапки и фона при пролистывании эпизодов на Mi Box 4 — гипотеза, проверяется на устройстве.
- Приёмка по скриншоту с TV требует пользователя; без него — только тесты и сборка.
