# S7 — Страница сериала: требования

Проект: [`docs/projects/plezy-tv/project.md`](../../projects/plezy-tv/project.md), этап S7. Концепция —
[concept.md](concept.md). Внешний вид — `docs/design/screens.md` §4, §7, `design-system.md`, `tokens.json`,
PNG `04-show-tab-show.png`, `04-show-tab-season.png`.

## 1. Назначение и объём

На TV сериал, открытый онлайн, показывается своим экраном вместо экрана деталей Plezy. Функции — как у
страницы сериала Plezy, внешний вид — по дизайну. На телефоне ничего не меняется.

Не входит: фильм (S8), офлайн-сериал из Загрузок, отдельный сезон без сериала, страница эпизода — они
остаются на экране Plezy. Своя панель плеера (S9).

## 2. Требования

### Вход
- **H1 Какой экран.** Сериал на TV онлайн открывается своим экраном из всех мест, где Plezy открывает детали
  через общий переход к деталям: карточки главной, библиотеки, хабов, поиска, «Продолжить просмотр» с
  настройкой «открывать детали», ссылки `plezytv://screen/item`, пункт меню «Подробнее». Сезон с известным
  сериалом и эпизод с известным сериалом открывают экран сериала (H8). Исключение: «Перейти к сериалу» из
  контекстного меню Plezy и переходы внутри экрана деталей Plezy остаются на экране Plezy (код в больших
  файлах апстрима, правка запрещена) — принятое ограничение.
- **H2 Загрузка.** Сразу рисуются фон и место шапки; если данных нет за 300 мс — статичный скелетон
  (`screens.md` §7). Фокус ставится на главную кнопку, когда она появилась, если пользователь сам его не
  перенёс.
- **H3 Ошибка.** Нет связи или сервер не ответил — сообщение и «Повторить» в фокусе; «Назад» уходит.

### Шапка и вкладки
- **H4 Шапка.** Логотип сериала (нет логотипа — название текстом), строка «годы · {n} сезонов · {n} эпизодов
  · возраст · студия» — только известные поля. Вкладки «Сериал / {название сезона}…» по списку сезонов
  сервера в порядке Plezy (с учётом настройки размещения спецвыпусков). Если Plezy показывает эпизоды без
  сезонов (одно- или «сплющенный» сериал), вкладки «Сериал / Эпизоды».
- **H5 Вкладки.** ←/→ по вкладкам переключает содержимое через 300 мс после остановки; выбранная
  подчёркнута. ↓ с вкладок — на главную кнопку («Сериал») или на последний эпизод в фокусе этой вкладки.
  ↑ из кнопок, рядов или эпизодов — на выбранную вкладку.

### Вкладка «Сериал»
- **H6 Содержимое.** Жанры чипами и оценки Plezy (включая оценки сообщества, если Plezy их показывает) в одну
  строку, описание до 3 строк, ряд кнопок, ряд «Сезоны {n}» (постер сезона, подпись «{n} эпизодов», бейдж
  непросмотренных или галочка), ниже прокруткой — «В ролях», «Трейлеры и дополнительно», «Похожие», если
  у Plezy для этого сервера они есть и не пусты. Пустые ряды не показываются. При вкладках «Эпизоды» (H4)
  ряда «Сезоны» нет.
- **H7 Кнопки.** Слева направо: главная, трейлер (если есть), перемешать, список (если у Plezy есть источник
  списка), просмотрено/не просмотрено, скачать, «⋯». Главная:
  - есть эпизод для продолжения или следующий непросмотренный — «Продолжить S{n} E{m} · осталось {t}», если
    он начат, иначе «Смотреть S{n} E{m}»; цель — как у Plezy («на очереди», иначе первый непросмотренный);
  - всё просмотрено (нет эпизода «на очереди» и нет непросмотренных обычных, не спецвыпусков) — «Пересмотреть», с первого обычного эпизода с начала;
  - иначе «Смотреть S1 E1» (первый эпизод сезона по умолчанию Plezy).
  Остальные кнопки делают то же, что одноимённые у Plezy: трейлер играет трейлер; перемешать — случайная
  очередь сериала; список — добавить/убрать (несколько источников — выбор источника, как у Plezy);
  просмотрено — для всего сериала; скачать — нет загрузок: диалог загрузки Plezy (версия, «держать синхронизированным», ограничения сети);
  всё скачано — как у Plezy (удалить через тот же диалог); частичные, на паузе, ошибочные и с правилом
  синхронизации — иконка показывает состояние, OK открывает экран Загрузок (упрощение); «⋯» — контекстное меню Plezy для сериала.
- **H8 Сезоны.** OK по постеру сезона — его вкладка, фокус на первом непросмотренном эпизоде (все
  просмотрены — первый).

### Вкладка сезона
- **H9 Эпизоды.** Ряд «{сезон} · {n} эпизодов» кадрами 16:9; под кадром всегда «S{n} E{m} · название» и
  длительность или «осталось {t}»; на кадре — галочка просмотренного, полоска прогресса начатого. Эпизоды
  подгружаются по мере прокрутки без остановки фокуса.
- **H10 Шапка эпизода.** На вкладке сезона под вкладками — эпизод в фокусе: «S{n} E{m} · название»,
  «длительность · дата выхода · просмотрено {a} из {b}» (последнее — только для начатого), оценка эпизода,
  описание до 3 строк. Фон и подкраска — из кадра эпизода в фокусе. Смена шапки и фона при быстром
  пролистывании не задерживает фокус.
- **H11 Фокус в сезоне.** При первом входе на вкладку — первый непросмотренный эпизод (все просмотрены —
  первый), ряд прокручен к нему; при возврате на вкладку — последний эпизод в фокусе.
- **H12 OK и меню.** OK по эпизоду — плеер с места остановки (как Plezy). Долгий OK / «Меню» — контекстное
  меню Plezy для эпизода.

### Возврат, обновление, «Назад»
- **H13 Назад.** На вкладке сезона — на вкладку «Сериал», фокус на главную кнопку. На «Сериал» — уход с экрана;
  экран, откуда пришли, обновляет сериал, если изменилось состояние просмотра (как у Plezy).
- **H14 После плеера.** Вкладка и эпизод сохраняются; если эпизод в фокусе досмотрен — фокус на следующий
  непросмотренный в этом сезоне. Главная кнопка, бейджи сезонов, галочки и прогресс обновлены.
- **H15 Действия.** После «просмотрено», меню и т. п. состояние экрана обновляется без перезахода.
- **H16 Вход на сезон/эпизод.** Открыт для сезона — его вкладка (H11). Для эпизода — вкладка его сезона,
  фокус на этом эпизоде.

### Прочие ряды
- **H17** «В ролях»: OK — фильмография человека, как у Plezy. «Трейлеры и дополнительно»: OK — играть.
  «Похожие»: постеры, OK — как карточка в других рядах (`navigateToMediaItem`), меню — меню Plezy.

## 3. Качество
- Переходы фокуса не ждут сети; на Mi Box 4 листание эпизодов не дёргается — проверяется на устройстве.
- Прокрутка страницы вниз к рядам: анимированно, мгновенно на слабых устройствах (правило `tv-ui.md`).

## 4. Ограничения и совместимость
- Только TV; телефон, офлайн и фильм — без изменений. Апстрим правится только маленькой точкой подключения
  в небольшом файле. Логика (цели воспроизведения, оценки, спецвыпуски, «сплющивание», наборы кнопок) —
  из Plezy; дизайн только оформляет.

## 5. Решения и допущения
- H1-исключение («Перейти к сериалу» из меню) принято координатором: покрыть его можно только правкой большого
  файла апстрима.
- Скачивание (H7): новая загрузка и удаление — как в Plezy; управление частичной загрузкой и правилами
  синхронизации — на экране Загрузок (упрощение).
- Оценка пользователя (звёзды) на шапке не входит — в дизайне её нет; доступна через «⋯», если Plezy
  даёт её в меню.

## 6. Согласование
Версия 2026-10-24 утверждена координатором по делегированию пользователя («прими все решения сам»).
Кнопки (H7) — решение пользователя.

## Примеры приёмки
- **A1** TV, сериал онлайн из библиотеки → свой экран; телефон → экран Plezy; сериал из Загрузок офлайн → Plezy.
- **A2** Фильм → экран Plezy, как до S7.
- **A3** Сериал с начатым S1E3 (осталось 35 мин) → «Продолжить S1 E3 · осталось 35 мин» в фокусе; OK → плеер.
- **A4** Всё просмотрено → «Пересмотреть»; ничего не смотрел → «Смотреть S1 E1».
- **A5** Нет трейлера → кнопки трейлера нет; нет источника списка → кнопки списка нет.
- **A6** OK по «Сезон 2» (E1, E2 просмотрены) → вкладка «Сезон 2», фокус на E3.
- **A7** ← → по вкладкам: содержимое меняется через 300 мс после остановки, не на каждом шаге.
- **A8** Пролистывание эпизодов → шапка эпизода и фон меняются под фокус; названия под кадрами видны все.
- **A9** «Назад» на сезоне → «Сериал», фокус на главной; ещё «Назад» → предыдущий экран.
- **A10** «Продолжить просмотр» (настройка «детали»), эпизод S2E4 → экран, вкладка «Сезон 2», фокус на E4.
- **A11** Досмотрел E3 в плеере, вернулся → фокус на E4, галочка на E3, главная кнопка — E4.
- **A12** «Просмотрено» на «Сериал» → все галочки, бейджи сезонов исчезли, кнопка «Пересмотреть».
- **A13** Однoсезонный «сплющенный» сериал → вкладки «Сериал / Эпизоды», ряда «Сезоны» нет.
- **A14** Сервер недоступен → ошибка с «Повторить»; восстановили, «Повторить» → экран.
- **A15** Сезон «Спецвыпуски» — вкладка по правилам Plezy; кнопка «Смотреть» не начинает со спецвыпуска.
- **A16** `plezytv://screen/item?…` с сериалом → свой экран.
