# S7 — Страница сериала: план

Контракт — [requirements.md](requirements.md) (H1–H17, A1–A16) и [design.md](design.md); они главнее плана.
Ветка `flow/s7-show-page`, checkout `/Users/underlow/Projects/PlezyTV`.

## 1. Результат

На TV онлайн-сериал открывается своим `TvShowScreen`: шапка, вкладки «Сериал / сезоны», кнопки Plezy,
ряд сезонов, ряды людей/экстр/похожих, вкладки сезонов с эпизодами и шапкой эпизода, фокус и «Назад»
по дизайну, обновление после плеера и действий. Фильм, офлайн, телефон — как раньше.

## 2. Общие договорённости

- Новый код — `lib/plezytv/tv_ui/show/`; тесты — `test/plezytv/tv_ui/show/`. Правила — `docs/plezytv/tv-ui.md`.
- Апстрим: только точка подключения в `lib/utils/media_navigation_helper.dart` (≤3 строки + импорт).
  Большие файлы (`media_detail_screen.dart`, `media_context_menu.dart`, `main.dart`) не правятся.
- Компоненты S6/S15/S16 используются; расширения без изменения поведения существующих вызовов.
- Тексты — `TvStrings` (новые — там же, по-английски как остальные константы, если так устроен файл) или
  строки Plezy `t.*` (`t.discover.cast`, `t.discover.extras`, `t.discover.moreLikeThis`, `t.common.seasonNumber`,
  `t.explore.episodeCount`, `t.discover.minutesLeft`, `t.discover.playEpisode` и т. п.).
- Раскладка и размеры — `screens.md` §4, §7, `design-system.md`, `tokens.json` (`size.seasonPoster` и т. п.),
  PNG `04-show-*`.
- Производительность: смена шапки/фона эпизода отложена (как `TvHero`), ряды ленивые, картинки
  декодируются в размер карточки.
- Проверки каждой задачи: `dart format` изменённых файлов, `flutter analyze`, тесты своих файлов и
  `test/plezytv/`. Полный `scripts/run_tests.sh` — в T3.
- Клиент сервера в тестах — подделка `MediaServerClient` в `test/plezytv/tv_ui/show/` (создаёт T1).

## 3. Задачи

### T1 — Точка подключения, контроллер, логика
Результат: design §3 «Точка подключения», `TvShowController`, `tv_show_logic.dart`; временный
`TvShowScreen`-заглушка не нужен — T1 может вернуть маршрут на минимальный экран, который T2 заменит.
- `TvUi.showDetailRoute(...)` по D1; хук в `navigateToMediaItemDetails`; тест: TV+show+online → свой маршрут;
  сезон с `parentId` и эпизод с `grandparentId` → свой маршрут с нужными `initial*`; эпизод только с
  `parentId`, movie, offline, не-TV → маршрут Plezy (A1, A2, A16).
- Контроллер: загрузка по design §3 с поколениями; сезоны, сплющенный режим (Plex `shouldShowPlexEpisodesDirectly`
  с prefs секции, Jellyfin ≤1 сезона), спецвыпуски по Plezy; постраничные эпизоды сезона; экстры, трейлер
  (как `_getPrimaryTrailer`: `trailerKey` Plex, иначе первый трейлер), похожие хабы, оценки с оценками
  сообщества, кандидаты списка; `refresh()`; `watchStateChanged`; правка кэша по событиям просмотра.
- Логика (чистые функции): метка и цель главной кнопки (H7, A3, A4, A15 — включая «непросмотрен только спецвыпуск» → «Пересмотреть»), строка метаданных (H4), выбор
  начальной вкладки и эпизода (H8, H11, H16), «просмотрено a из b».
- Проверка: тесты логики и контроллера на подделке клиента (порядок, отброс устаревших ответов, ошибка).

### T2 — Экран: шапка, вкладки, сезоны, эпизоды, фокус
Результат: `TvShowScreen` по H2–H6 (без ряда кнопок и нижних рядов — места под них), H8–H14, H16.
- Фон, шапка, `TvTabs` с переключением через 300 мс, скелетон через 300 мс, ошибка с «Повторить».
- Вкладка «Сериал»: жанры, оценки, описание, место ряда кнопок (главная кнопка уже есть и запускает цель),
  ряд «Сезоны» (постер 160×240, «{n} эпизодов», бейдж непросмотренных/галочка), OK → вкладка сезона.
- Вкладка сезона: шапка эпизода в фокусе, ряд `TvEpisode` 400×225 с подгрузкой, OK → плеер с
  `onRefresh`, меню → `MediaContextMenu`.
- Фокус ↑/↓/←/→ и «Назад» (H5, H11, H13), возврат с bool, H14 после плеера.
- Проверка: виджет-тесты A3, A6, A7, A9, A10, A11, A13, A14 (на подделке). A8 и скорость на Mi Box —
  приёмка на устройстве.

### T3 — Кнопки, нижние ряды, обновление, CI и документация
Результат: H7 полностью, H6 нижние ряды, H15, H17; D2 предупреждение в `plezytv-upstream.yml`;
`docs/plezytv/tv-ui.md` — раздел о точке подключения деталей (для S8) и экране сериала.
- Кнопки: трейлер, перемешать, список (выбор источника), просмотрено, скачать (D3), «⋯» (меню через
  `GlobalKey<MediaContextMenuState>`, как S16); видимость как у Plezy.
- Ряды «В ролях» (OK → `navigateToPersonMedia`), «Трейлеры и дополнительно» (OK → плеер), «Похожие»
  (`navigateToMediaItem`, меню Plezy); прокрутка страницы к рядам по правилу `tv-ui.md`.
- Проверка: виджет-тесты A5, A12; полный `scripts/run_tests.sh`, `flutter analyze`, сборка APK
  (`flutter build apk --debug` или как в предыдущих этапах).
