# S15 — принятые решения по находкам ревью

- **T1, смена режима hero (принято пользователем 2026-10-24).** При 600↔420 высота анимируется 250 мс,
  а верх текста (110↔72) и число строк описания меняются за один кадр. Оставлено как есть; вернуться,
  если рывок заметен при проверке на TV.

## Для T4/T5 (из ревью T2)

- `TvHomePlayback.forContext` вызывает `ModalRoute.of(context)`: создавать один раз на state главной
  (лениво или в `didChangeDependencies`), не в `initState` и не в `build` (иначе сбрасывается флаг
  «уже запускается»).
- Колбэк `isCurrent` должен оставаться true, пока плеер закрывает главную («выбран раздел главной»),
  а не по фокусу/видимости — иначе плеер отменит собственный старт.
