# Форк Plezy: план доделок TV-интерфейса

Цель: Plezy на Android TV с интерфейсом не хуже официального Plex — на своих телеках
(Xiaomi в гостиной, Mi Box 4, TCL).

**Plex не копируем 1-в-1.** По функциям — почти паритет (кроме того, что в «Не делаем»).
Внешне Plex — ориентир: узнаваемо похоже, но доработано и лучше. Где Plezy уже удобнее
(названия под карточками, серии в Continue Watching, названия эпизодов, экран настроек) —
оставляем по-плезиевски. Сравнение ниже — источник идей, а не ТЗ «сделать как в Plex».

Источники (2026-10-23):
- скриншоты Plex 2026.20.0 и Plezy 2.24.0 с Xiaomi: `docs/research/screenshots/plex/`, `docs/research/screenshots/plezy/`;
- исходники github.com/edde746/plezy (main, v2.24.0) и его issues;
- контролы плеера — фото с экрана в `docs/research/screenshots/photos/` (`screencap` во время видео даёт белый кадр).

## Что важно знать про Plezy до начала

- **GPL-3.0.** Форк обязан оставаться GPLv3 с открытым кодом.
- **Не только Plex:** ещё Jellyfin, Emby, Trakt и др.; платформы — телефоны, десктоп, tvOS, Android TV.
  TV-раскладка — не отдельный слой, а ветки `PlatformDetector.isTV()` внутри общих экранов (~26 файлов).
- **Апстрим релизится еженедельно** и в основном про плеер. Автор принципиально не добавляет
  переключатели внешнего вида и отказал в табах сезонов на TV (#2657), скрытии hero (#2784),
  отключении фона/часов (#2701). Свой UI в апстрим не примут → форк.
- **Стоимость поддержки форка** — главный риск. Решение — см. «Архитектура форка» ниже.
- **Фокус/D-pad** (`lib/focus/`, ~5k строк: память фокуса, locked hub) — хрупкое место.
  Любое изменение геометрии экрана = перепроверка навигации пультом.
- Цвета, радиусы, анимации собраны в `lib/theme/mono_tokens.dart`, `mono_theme.dart`,
  фокус — `lib/focus/focus_theme.dart`. Размеры карточек — магические числа по экранам
  (`tv_browse_rail.dart`, `media_grid_delegate.dart`, `media_detail_screen.dart`).

## Производительность — приоритет

Красоту не отбрасываем из-за тормозов: любую нужную доработку берём, продумываем реализацию
и делаем её быстрой. Медленная версия — не повод отказаться от фичи, а задача на оптимизацию
до слияния.

- **Эталонное устройство — Mi Box 4** (2 ГБ, Android 9), самый слабый из трёх. Что плавно
  на нём, то плавно везде. Xiaomi — второе устройство для проверки.
- **Бюджет** (уточнить после первых замеров апстрима): прокрутка рядов и сетки без пропуска кадров
  при зажатой стрелке, открытие карточки фильма/сериала — не дольше апстрима, холодный старт —
  не дольше апстрима. Наш экран медленнее апстримного = регрессия.
- **Замер, а не ощущения:** profile-сборка, `adb shell dumpsys gfxinfo <pkg>` (janky frames,
  перцентили), время открытия экранов по логам с нашим тегом. Сначала снять базу на апстримном
  Plezy 2.24.0, потом сравнивать каждый наш экран с ней.
- **Правила для наших экранов:**
  - картинки декодировать под размер показа (`cacheWidth/cacheHeight`), а не в полном разрешении;
    следить за размером кэша изображений на 2 ГБ;
  - без `BackdropFilter`/размытия и тяжёлых теней на TV; градиенты вместо blur;
  - фон под цвет обложки: цвет считать вне UI-потока, по уменьшенной картинке, кэшировать;
    смена фона — простой кроссфейд;
  - ленивые списки (`ListView.builder`/слайверы), предзагрузка соседних постеров на шаг вперёд;
  - анимации фокуса — только transform/opacity, без перерасчёта раскладки;
  - минимум перестроений при смене фокуса: шапка с описанием обновляется с небольшой задержкой
    (debounce), а не на каждое нажатие при быстрой прокрутке.
- **Перед каждым релизом** — прогон замеров на Mi Box 4, результаты в таблицу в этом файле
  или рядом.

## Архитектура форка (решено)

1. **Основную ветку апстрима должно быть можно подмерживать всегда.** Свой интерфейс —
   отдельные TV-версии экранов в своей папке (например `lib/tv/`), только для TV.
   Мобильные/десктопные экраны и общий код не трогаем.
2. **Большие файлы апстрима не трогаем** (`media_detail_screen.dart` 5k, `tv_browse_rail.dart` 2.3k,
   `main_screen.dart` 2.3k, `discover_screen.dart` 1.7k). Наши экраны их не правят, а заменяют:
   переиспользуют провайдеры, сервисы, модели, фокус-слой (`lib/focus/`) и мелкие виджеты.
3. **Точка подключения — одна-две маленькие правки** в апстриме: развилка при навигации
   «если TV и включён наш UI — открыть наш экран». Желательно одна функция-роутер, чтобы конфликт
   при мерже был в одном месте.
4. **Переключатель «наш UI / апстримный»** в настройках — запасной вариант, если наш экран
   ещё не готов или сломался после мержа.
5. Мерж апстрима регулярно (раз в неделю-две, под их релизы), после мержа — сборка и прогон
   основных сценариев пультом.
6. Код открытый (GPL-3.0), репо публичное.

Следствие: страницу сериала и главную делаем своими экранами с нуля, а не правкой апстримных.

## Отличия по экранам

Ⓟ = в Plex лучше, Ⓩ = в Plezy лучше, ≈ = примерно одинаково.

### Навигация и главная
| | Plex | Plezy |
|---|---|---|
| Меню | плавающая «таблетка» из 4 иконок, раскрывается в панель с подписями и сервером под каждой библиотекой | рейка иконок во всю высоту, раскрывается; есть скрытые библиотеки ≈ |
| Главная — вкладки | For You / Trending / Activity Ⓟ | вкладок нет, только хабы сервера |
| Hero | лого, год, длительность, жанры, рейтинг, описание, **актёры** | лого, тип, оценки, рейтинг, описание; без жанров и актёров |
| Фон | подкрашивается под цвета обложки — живо Ⓟ | почти чёрный (тема OLED) |
| Панель сверху | только часы | часы + 5 иконок без подписей (обновить, профили, устройство, активность, аватар) — непонятно, что есть что Ⓟ |
| Карточки в рядах | только постер с бейджами | постер + **название и серия/год под ним** Ⓩ |
| Continue Watching | без отдельных серий | показывает и серии (S1 E1 · Underwater) Ⓩ |
| Профили | выбор «Кто смотрит?» при запуске | есть (`requireProfileSelectionOnOpen`), проверить, включено ли у нас |

### Watchlist / мои списки
- Plex: отдельный пункт «My Lists» → вкладки Watchlist / Lists / Recommended, сетка 375 шт. с фильтром и сортировкой.
- Plezy: watchlist **есть**, но спрятан рядом в разделе Explore; фильтров/сортировки нет (#2737, PR #2725);
  нет кнопки «Смотреть», если фильм уже лежит на сервере (#1917). Пользовательских Lists нет.

### Библиотека (сетка)
- ≈ Одинаковая структура: Recommended / Browse / Collections / Playlists, 6 колонок, A–Я сбоку.
- Plex показывает **текущую сортировку и число элементов** («by Title · 175 Items») Ⓟ;
  Plezy — кнопки Filters / Sort без текущего состояния.
- Plezy: в сетке сериалов **рейтинг дублируется** (`IMDb 8.1  8.1`) — баг/лишний бейдж.
- Plezy: бейдж с числом на сериале (4, 12…) непонятен без подписи — сезоны или непросмотренные серии.
- Plex: на вкладке Recommended видны пустые заглушки, пока грузится; Plezy быстрее.

### Карточка фильма
| | Plex | Plezy |
|---|---|---|
| Метаданные | год, длительность, **жанры**, рейтинг, оценки 4 источников, **режиссёр** | год, рейтинг, длительность, звёзды, оценки; **IMDb показан дважды** (9.7 и 8.0) — путает |
| Кнопки | белая «Watch» с подписью + круглые иконки | круг play **без подписи** + плоские иконки |
| Тех. чипы | 1080p, звук, субтитры ≈ | то же одной строкой ≈ |
| Актёры | круглые портреты | скруглённые квадраты, переход на страницу актёра ≈ |
| Отзывы критиков | блок Ratings & Reviews Ⓟ | нет |
| Похожие | есть ≈ | есть ≈ |
| Назад | кнопкой пульта | ещё стрелка на экране (на TV лишняя) |

### Страница сериала — главное отличие
- Plex: вкладки **Show / Season 1 / Season 2**. На Show — описание сериала, жанры, кнопка
  «Resume S1 E1 · 35m left», **постеры сезонов**. На вкладке сезона — ряд больших кадров эпизодов,
  шапка показывает выбранную серию (название, дата, описание, режиссёр, тех. чипы).
- Plezy: одна страница, **все сезоны рядами эпизодов подряд**; шапка сразу показывает текущую серию,
  а не сериал — описания самого сериала и жанров не видно. Кнопка «▶ S1E1» без «осталось 35 мин».
  Есть shuffle. Под кадрами эпизодов — **названия и длительность** Ⓩ (в Plex только «E1»).
- Автор отказал в табах (#2657), но #2515 (сезоны как табы, есть макеты) открыт.
- Спешлы (Season 0) обрабатываются плохо (#2012, #2321).

### Поиск
- Plex: своя сетка букв для пульта слева, результаты справа плиткой 2 в ряд, **история поиска**,
  **популярные запросы** на пустом экране, фильтры All/Films/TV/Music/Live TV/Cast & Crew/Services,
  ищет и по Plex Discover (не только своё).
- Plezy: системная клавиатура Android **закрывает пол-экрана**, открылась в русской раскладке;
  результаты списком по одному — видно 2 штуки; на пустом экране ничего; истории нет.
  В коде есть своя `tv_virtual_keyboard.dart` — **проверить**, почему на Xiaomi открылась системная
  (возможно, из-за `input text`, которым пользовался агент).

### Настройки и профиль
- Plex: меню профиля (Switch Profile, Notifications, Friends, Services, Server, Settings) + модальный список.
- Plezy: полноэкранный список с иконками и подписями Ⓩ. Первым пунктом — донат.

### Плеер
Фото с экрана: `docs/research/screenshots/photos/` (01.12.02–01.12.18 — Plex, 01.12.22–01.12.29 — Plezy на TCL).

| | Plex | Plezy |
|---|---|---|
| Панель | минимальная: play, время, полоса, остаток; справа две иконки (субтитры, настройки); сверху название серии, «S2·E1·сериал·58 min» и часы | полный ряд: пред./назад/−10/пауза/+10/вперёд/след., «Ends at 02:24», справа настройки, дорожки, zoom; сверху стрелка назад, название, длительность, часы |
| Внизу (стрелка ↓) | **Play Queue** — ряд следующих серий с кадрами и названиями Ⓟ | — |
| Настройки | узкая панель справа, видео остаётся видно: Quality, Subtitles, Audio, Playback Options — с текущими значениями | большое модальное окно по центру, перекрывает видео: скорость, zoom, качество (с битрейтом), sleep timer, audio/subtitle sync, автоплей, аудиовыход Ⓩ по возможностям |
| Субтитры/звук | отдельные списки в той же правой панели, язык + родное название | одно окно, два столбца звук/субтитры, поиск субтитров Ⓩ; но технический мусор в подписях (`APPLICATION/X-SUBRIP`) |
| Конец фильма | — | «Ends at» — полезно Ⓩ |

**Решение: панель плеера переделываем, за основу — старая версия Plex** (там была удобнее).
Детали — обсудить отдельно (найти скриншоты старого плеера Plex, решить, что из Plezy оставить:
«Ends at», sleep timer, sync, поиск субтитров). Плеер — свой виджет контролов в `lib/tv/`,
сам движок воспроизведения (mpv/ExoPlayer) апстримный не трогаем.

По коду Plezy есть: skip intro/credits, Play Next с отсчётом, пресеты качества. Нет экрана
post-play с рекомендациями. Запросы в апстриме: превью при перемотке на TV (#2130), запоминание
фокуса в контролах (#2678), показ direct play / transcode (#2692).

### Чего в Plezy нет совсем / по-другому
- «On Plex» / бесплатные стриминги Plex — нет (и, вероятно, не нужно).
- Канал рекомендаций / Watch Next в лаунчере Android TV — нет (#1898). Projectivy умеет показывать
  такие каналы — полезная доделка.
- Trending, Activity (что смотрят друзья) — нет.
- Зато есть то, чего нет в Plex бесплатно: загрузки, Live TV без Plex Pass, Jellyfin, Seerr.

## Ещё не проверено (сценарии на телеке)

Прогнать в обоих приложениях, когда телек свободен:
1. досмотреть серию → следующая серия, автоплей, skip intro;
2. добавить в watchlist / отметить просмотренным — сколько нажатий;
3. страница актёра → фильм из фильмографии;
4. коллекция, плейлист;
5. Explore и Downloads в Plezy (не сняты);
6. скорость на Mi Box 4 (2 ГБ): открытие карточки, прокрутка длинного ряда (#2525 «Slow UI»);
7. поиск в Plezy своей клавиатурой, а не через `input text`.

## План доделок

Оценка: ценность для нас (В/С/Н) / сложность (В/С/Н).

### Этап 0 — подготовка
- Форк, сборка под Android TV.
- **Новое название**: имя приложения, иконка, баннер для лаунчера, свой `applicationId`
  (сейчас `com.edde746.plezy` в `android/app/build.gradle.kts`) и своя схема deep link
  (сейчас `plezy://`) — чтобы ставился рядом с оригинальным Plezy и не путался с ним.
  Название выбрать.
- Базовые замеры производительности апстримного Plezy на Mi Box 4 и Xiaomi (см. «Производительность»).
- Каркас `lib/tv/` + развилка-роутер + переключатель «наш UI / апстримный».
- Сборка APK в GitHub Actions, релизы на GitHub.
- Проверка мержа апстрима в CI: раз в неделю пробовать смержить main апстрима и собрать.

### Этап 0.5 — настройки и обслуживание через adb
- **Экспорт/импорт настроек на TV.** В Plezy он уже есть (`SettingsExportService`, раздел Backup
  в `settings_screen.dart`), но на Android TV скрыт: там нет выбора файла. Сделать на TV
  экспорт и импорт в фиксированный файл, например
  `/sdcard/Android/data/<pkg>/files/settings.json` — забирать и класть через `adb pull/push`.
- **Импорт по команде adb**, без пульта: интент вроде
  `am start -n <pkg>/.MainActivity --es import_settings <путь>` или импорт файла при старте,
  если он появился. Так один и тот же набор настроек раскатывается на все три телека.
- Проверить, что входит в экспорт: только настройки или ещё серверы/профили/логин. Токены
  в файл не класть (или отдельный флаг), файл не в git — как `apps.ab` в `tv/snapshots`.
- Встроить в `snapshot.sh` скилла `tv`: снимок забирает и экспорт настроек нашего приложения.
