# docs/design

Дизайн TV-интерфейса PlezyTV (Android TV, 1920×1080, управление пультом).

| Файл | Что внутри |
|---|---|
| [`brief.md`](brief.md) | Исходный бриф: зачем и что нужно |
| [`tokens.json`](tokens.json) | Все числа: цвета, шрифт, размеры текста, отступы, радиусы, размеры элементов, масштаб фокуса, длительности анимаций |
| [`design-system.md`](design-system.md) | Правила: цвет и подкраска фона, типографика, сетка, шаблоны строк, 11 компонентов со всеми состояниями |
| [`player.md`](player.md) | Плеер и экран после просмотра: раскладка, навигация, тайминги, рекомендации по открытым вопросам |
| [`screens.md`](screens.md) | Экраны: раскладка, навигация стрелками, память фокуса, загрузка, пустые экраны и ошибки |
| [`screens/`](screens/) | PNG-макеты 1920×1080 и лист компонентов `00-components.png` |
| [`mockups/`](mockups/) | Исходники макетов (HTML/CSS/JS) и `render.sh`, который пересобирает PNG через headless Chrome |

Макеты сделаны в реальных размерах из `tokens.json`: 1 px на PNG = 1 px экрана 1080p.
Тексты на макетах — пример для русской локали. Обложки — заглушки.

## Ограничения железа

Целевое устройство — Mi Box 4 (2 ГБ), поэтому:
- никакого размытия, «стекла», теней с размытием и свечения;
- анимируются только масштаб и прозрачность;
- затемнение — плоская полупрозрачная подложка;
- backdrop декодируется не крупнее 1280 px по ширине;
- скелетоны загрузки без анимации блеска;
- на слабых устройствах переходы фокуса мгновенные.

## Пересборка PNG

```bash
docs/design/mockups/render.sh
```

## Как использовать

Из дизайна берётся внешний вид. Функциональность и логика (набор настроек, шаги перемотки,
источники оценок и т.п.) — из кода Plezy; где макет с ним расходится, решает реализация.
