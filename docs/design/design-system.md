# PlezyTV — дизайн-система (Android TV, 1080p)

Числа — в [`tokens.json`](tokens.json), здесь — правила их применения. Готовые экраны —
[`screens/*.png`](screens/), навигация фокусом и состояния экранов — [`screens.md`](screens.md).
Если PNG и текст расходятся, верен текст и `tokens.json`; о расхождении сообщить.

## 0. Принципы

1. **Фокус виден всегда и сразу.** Элемент в фокусе меняет два признака: белую обводку или
   заливку и масштаб. Акцентный цвет для фокуса не используется. Акцент — только главное действие,
   прогресс, текущий раздел и число непросмотренных, чтобы не путать «выбрано» и «в фокусе».
2. **Дёшево для Mi Box 4.** Нельзя: размытие фона, «стекло», тени с размытием, свечение вокруг
   фокуса, анимация чего-либо кроме масштаба и прозрачности. Затемнение — плоская полупрозрачная
   подложка. Фон под обложку — один градиент и одна картинка backdrop, декодированная не крупнее
   1280 px по ширине. На слабых устройствах переходы фокуса мгновенные, без анимации.
3. **Никаких пилюль и кругов у кнопок.** Кнопки — скруглённые прямоугольники (`radius.button = 12`),
   иконочные кнопки и клавиши поиска — скруглённые квадраты (`radius.iconButton = 16`).
   Круглыми остаются только аватары актёров.
4. **Безопасные поля:** `safeX = 96`, `safeY = 54`. Контент начинается с `space.contentLeft = 200`
   (справа от свёрнутого меню). Ряды уходят за правый край экрана — так видно, что дальше есть ещё.

## 1. Цвет

| Роль | Токен | Hex |
|---|---|---|
| Базовый фон | `color.bg.base` | `#0E0F12` |
| Поверхности | `surface.1/2/3` | `#1A1C21` / `#24272D` / `#2F333A` |
| Затемнение под раскрытым меню | `surface.scrim` | `#0E0F12B3` |
| Текст: основной / вторичный / третичный | `text.primary/secondary/tertiary` | `#F2F3F5` / `#B4B8C0` / `#7C818B` |
| Акцент | `accent.default` / `accent.pressed` | `#E5A00D` / `#C98A05` |
| Фокус | `focus.ring`, `focus.fill` | `#FFFFFF`, `#F2F3F5` |
| Скелетоны | `bg.skeleton`, `bg.skeletonLine` | `#1A1C21`, `#24272D` |

### Подкраска фона под обложку
- Используется на главной (hero), в карточке фильма и на странице сериала. Библиотека, поиск,
  Watchlist и экраны состояний — на `bg.base` с лёгким холодным оттенком сверху.
- `tint` — доминантный цвет артворка, приведённый в HSL: насыщенность не больше 0.45, светлота
  в диапазоне 0.10–0.18. Считать один раз и кэшировать по элементу.
- Фон = вертикальный градиент от `lerp(bg.base, tint, 0.44)` сверху к `bg.base` к 85% высоты.
- Backdrop справа (1300×780) плавно уходит в фон слева (55% ширины) и снизу (45% высоты).
  Плюс подложка слева на 1100 px под текстом.
- Смена фона — кроссфейд `motion.bgTintCrossfade` (400 мс), когда фокус простоял на элементе
  `motion.heroDebounce` (300 мс).
- Контраст текста к итоговому фону — не ниже 4.5:1.

## 2. Типографика

Шрифт **Manrope** (геометрический, полная кириллица), веса 400/500/600/700/800. Шкала — `type.*`.

- Название карточки — одна строка с многоточием. Подпись (год, «3 сезона», «S1 E1») — одна строка.
- Заголовок hero или карточки: если есть логотип-артворк, показываем его (не больше 560×200)
  и текстом не дублируем. Без логотипа — `display`, до двух строк. На макетах логотип
  изображён набранным текстом.
- Описание — `bodyLarge`: 3 строки в hero и на странице сериала, 4 в карточке фильма,
  2 в сжатом hero.
- Длинные русские названия не уменьшают шрифт, а обрезаются многоточием. Проверочная строка —
  «Приключения капитана Врунгеля: возвращение».

## 3. Сетка и отступы

- Шаг 8 px, отступы — `space.*`.
- Ряды: между рядами `rowGap 48`, между карточками `cardGap 24`, от заголовка до карточек 16.
- Сетка (библиотека, Watchlist): 6 колонок по 228×342 с зазором 32, начинается с x = 200, y = 230.
  Колонка букв А–Я — x = 1776, ширина 48, шаг 24.
- Кнопки действий в ряду — зазор `actionsGap 24`, чтобы увеличенная кнопка в фокусе не касалась соседней.

## 4. Тексты и шаблоны

Все подписи на макетах — пример для русской локали. Строки с подстановкой — шаблоны, их собирают
из данных и переводят как единую строку с параметрами:

| Шаблон | Пример | Где |
|---|---|---|
| `Смотреть` | Смотреть | главная кнопка, если не начато |
| `Продолжить · осталось {t}` | Продолжить · осталось 1 ч 20 мин | главная кнопка фильма |
| `Продолжить S{n} E{m} · осталось {t}` | Продолжить S1 E3 · осталось 35 мин | главная кнопка на вкладке «Сериал» |
| `Смотреть S{n} E{m}` | Смотреть S1 E1 | сериал не начат |
| `S{n} E{m} · {title}` | S1 E3 · Прошлое и настоящее | подпись кадра эпизода, шапка вкладки сезона |
| `осталось {t}` | осталось 35 мин | подпись в «Продолжить просмотр» |
| `{show} · осталось {t}` | Тьма · осталось 35 мин | вторая строка эпизода в «Продолжить просмотр» |
| `{n} непросмотренных` | 12 непросмотренных | подпись постера сериала в фокусе |
| `{n} сезон/сезона/сезонов` | 3 сезона | подпись постера сериала |
| `{n} эпизодов` | 10 эпизодов | счётчик ряда эпизодов |
| `по названию · {count}` | по названию · 175 | кнопка сортировки библиотеки |
| `по дате добавления · {count}` | по дате добавления · 32 | кнопка сортировки Watchlist |
| `Фильтры · {n}` | Фильтры · 2 | кнопка фильтров, если активны фильтры |
| `просмотрено {a} из {b}` | просмотрено 17 из 52 мин | метаданные эпизода |
| `По запросу «{q}» ничего нет…` | По запросу «врнгл» ничего нет… | поиск без результатов |
| `Нет связи с сервером «{server}»` | Нет связи с сервером «Домашний» | экран ошибки |

`{t}` — длительность: «35 мин», «1 ч 20 мин». Числительные склоняются по правилам локали
(1 сезон, 3 сезона, 5 сезонов).

## 5. Компоненты

У каждого компонента четыре состояния: **обычный / в фокусе / нажат / неактивен**. Все они
нарисованы на [`screens/00-components.png`](screens/00-components.png). Переходы: вход в фокус
`focusIn 120`, выход `focusOut 100`, нажатие `press 80`, кривая `easeOutCubic`.

### 5.1 Постер 2:3
- В ряду 216×324, в сетке 228×342, сезон на странице сериала 160×240, радиус `card 10`. Пока картинка не загрузилась — плейсхолдер `surface.2`.
- Под ним (отступ 20): название `body`, подпись `caption` `text.tertiary` (год или «3 сезона»).
- **Фокус:** картинка ×1.08 от нижнего края, белое кольцо 4 px с зазором 3 px, название
  становится `text.primary` 600. Подписи не масштабируются.
- **Нажат:** ×0.97 от размера в фокусе. **Неактивен:** прозрачность 0.4, без кольца.

### 5.2 Кадр эпизода 16:9
- 400×225, радиус `card`. Полоса прогресса высотой 6 px внутри картинки по нижнему краю.
- Строка 1 — `S{n} E{m} · {название}` (`body`), строка 2 — длительность или `осталось {t}` (`caption`).
- Состояния — как у постера, но масштаб в фокусе `focus.episodeScale = 1.05` (нажат — ×0.97 от него).
  При 1.08 кольцо широкой карточки подходит к соседней на 1 px; при 1.05 остаётся 7 px.
- В «Продолжить просмотр» показываются серии, а не сериалы.

### 5.3 Горизонтальный ряд
- Заголовок `title` на x = 200, рядом счётчик `caption`.
- Над карточками запас 24 px (итого 40 от заголовка), чтобы увеличенная карточка с кольцом
  не наезжала на заголовок: (scale − 1)·h + ring 7 = 33 px для постера 324.
- Прокрутка `rowScroll 150`: карточка в фокусе остаётся на позиции первой видимой, кроме начала ряда.
- Ряд сам не фокусируется. Его «состояние» — есть ли фокус внутри.

### 5.4 Кнопки
**Главная** — h 64, отступы по бокам 32, `radius.button 12`, иконка 28 + текст `label`.
Обычная — заливка `accent`, текст `onAccent`. В фокусе — белая заливка, тёмный текст, ×1.05.
Нажата — `accent.pressed`, ×0.97. Неактивна — `disabled.fill` + `disabled.text`. Текст обязателен
(шаблоны в разделе 4), кнопки «голый play» нет.

**Вторичная** — те же размеры, `surface.3`, текст `text.primary`; в фокусе белая. Малая
вторичная (h 52, отступы 24) — для недавних запросов в поиске.

**Иконочная** — 64×64, `radius.iconButton 16`, иконка 30, фон `surface.3`. В фокусе белая, ×1.05.
Подпись (`caption`, 10 px ниже) видна только в фокусе: «В список», «Просмотрено», «Трейлер», «Ещё».
Место под подпись зарезервировано всегда, чтобы ряд не прыгал.

### 5.5 Чипы
- h 36, отступы 14, `radius.chip 8`, текст `badge`.
- Жанр — `surface.2`, текст `secondary`. Фокусируется только в карточке; состояния — как у кнопки.
- Технические (4K, HDR10, Dolby Vision, Atmos 7.1, 5.1) — обводка 1.5 px `text.tertiary`, без заливки,
  не фокусируются.

### 5.6 Блок оценок
- Одна оценка на источник. Порядок: IMDb, TMDB, Rotten Tomatoes (критики), RT (зрители),
  Кинопоиск — если есть. Дубли по источнику отбрасываются.
- Каждая оценка: плашка источника высотой 24 в его цвете (`rating.*`) и число `body` 600.
  Между оценками 24. Не фокусируется.

### 5.7 Вкладки
- h 52, отступы 24, текст `label`. Блок вкладок сдвинут влево на 24, чтобы текст первой вкладки
  стоял на x = 200.
- Обычная — `text.secondary`. Выбранная — `text.primary` и подчёркивание 4 px `accent`.
- В фокусе — белая заливка, радиус 12, ×1.05. Нажата — заливка `text.secondary`.
  Неактивна — прозрачность 0.4.
- Вкладка выбирается по фокусу, без OK: контент меняется через 300 мс после остановки фокуса.

### 5.8 Бейджи
Правый верхний угол картинки, отступ 8, `radius.badge 6`, текст `badge`. Не фокусируются.
- **Просмотрено** — квадрат 32 `status.watched` с галочкой.
- **Непросмотренные** (сериал, сезон) — `accent` с числом, ширина от 36, высота 32. Число —
  непросмотренные эпизоды. В фокусе подпись под постером меняется на `{n} непросмотренных`
  акцентным цветом — так понятно, что значит число.
- **Прогресс** — полоса внизу картинки, не бейдж.
- **На сервере** (Watchlist) — плашка `status.onServer` в левом верхнем углу.

### 5.9 Боковое меню
- **Свёрнуто:** колонка иконок 72×64 с отступом 32 от левого края, фон прозрачный.
  Подписей нет, текущий раздел отмечен полоской `accent` 4×32 слева.
- **Раскрыто** (фокус вошёл в меню): панель 392 px, `surface.1`, иконки с подписями `label`.
  Остальной экран под плоской подложкой `surface.scrim`, без размытия. Раскрытие — 180 мс,
  анимируется обрезка ширины, а не масштаб.
- **Пункты:** Поиск, Главная, библиотеки сервера (Фильмы, Сериалы, Музыка…), Список — разделитель —
  Настройки, профиль (имя пользователя).
- **Состояния пункта:** в фокусе белая заливка, нажат — `text.secondary`, неактивен — 0.4.

### 5.10 Пункт настроек
- h 88, ширина до 1200. Слева иконка 36, затем заголовок `body` и описание `caption`. Справа
  текущее значение `body` `secondary` и шеврон.
- В фокусе — `surface.3` и белая обводка 4 px, радиус 12, без масштаба. Нажат — `surface.2`
  с обводкой. Неактивен — 0.4 и в описании причина («не поддерживается устройством»).

### 5.11 Клавиатура поиска
- Клавиши 64×64, `radius.iconButton`, зазор 12, 6 колонок, фон `surface.2`. В фокусе белая, ×1.05.
- Служебные клавиши шириной в 2 клетки: пробел, ⌫, «Очистить». Переключатель РУС / ENG / 123 —
  выбранный отмечен полосой `accent` снизу.
