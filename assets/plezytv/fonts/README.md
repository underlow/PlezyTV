# Manrope

`Manrope[wght].ttf` is the official Manrope variable font from
https://github.com/google/fonts/tree/main/ofl/manrope (weight axis 200–800).
The upstream project is https://github.com/sharanda/manrope.
Distributed under the SIL Open Font License in `OFL.txt`.

TV styles use weights 400, 500, 600, 700 and 800 and set both Flutter
`fontWeight` and the `wght` font variation explicitly.
