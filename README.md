# PlezyTV

**PlezyTV is an unofficial fork of [Plezy](https://github.com/edde746/plezy) by edde746 with a reworked interface for Android TV.**

All the client itself — playback, Plex/Jellyfin/Emby support, sync, downloads — is Plezy's work. This fork only adds its own TV screens
(show and movie pages, player controls, search, home and library) aimed at a remote control and at staying fast on low-end
boxes such as the Mi Box 4. Mobile and desktop screens are left as upstream has them, and upstream is merged regularly.

PlezyTV installs side by side with the original Plezy. It is not affiliated with or supported by the Plezy author — please
report issues with this fork here, not upstream. If you don't specifically want the TV interface, use
[Plezy](https://github.com/edde746/plezy) itself.

Status: early work in progress, no releases yet.
